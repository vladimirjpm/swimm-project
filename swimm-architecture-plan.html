Roadmap / Future

Hosting Evolution

Сейчас PostgreSQL в Docker · Clean Architecture всё работает локально
Потом — БД Бесплатный PostgreSQL в Neon managed · free tier
Потом — API Azure App Service · или Azure Container Apps родное для .NET
При росте БД → Azure PostgreSQL Flexible Server когда появятся пользователи
Архитектура строится вокруг PostgreSQL + Npgsql, не вокруг Azure. Поэтому переезд на Azure / Neon / Supabase / Railway / любой VPS — это простая замена connection string, без изменений кода. Это одна из причин, почему переход на PostgreSQL сейчас — хорошее решение.

AI Extension Points (future)

Цель: заложить seam-ы так, чтобы и простой LLM сейчас, и Microsoft Agent Framework 1.0 потом внедрялись за один и тот же интерфейс — сменой реализации в Infrastructure, без правок контроллеров и домена. Реализация — после Clean Architecture (Шаг 4).

Coach tools — обычные C#-методы

Детерминированные функции над данными заплывов. В режиме прямого SDK подключаются как function-calling tools; в MAF — как agent tools / MCP. Методы одни и те же — инвестиция не пропадает.

CompareSwimmers(a, b, period)кто прогрессировал лучше
SuggestTrainingFocus(swimmerId)слабые дистанции/стили

Сейчас: прямой SDK — tool-loop вручную, один провайдер за интерфейсом. Потом (MAF 1.0): те же tools регистрируются как agent tools/MCP, добавляются память (threads) и multi-agent (DataAgent → CoachAgent → Critic). IVirtualCoach не меняется.

Каталог агентов — расширяемый (агентов может быть много)

Контроллер зависит от роутера/каталога, а не от конкретных агентов. Новый агент = реализовать IAgent + зарегистрировать в DI. Контроллеры и домен не трогаются. В MAF это раскрывается в multi-agent с handoff/маршрутизацией.

IAgentОбщий контракт: Name · Description · CanHandle(context) · HandleAsync(message, context). Каждый агент — отдельная реализация.
IAgentCatalogРеестр всех агентов (discovery). Регистрация через DI — добавил класс, агент доступен.
IAgentRouterВыбирает агента под запрос (или отдаёт оркестрацию/handoff в MAF). Точка входа для контроллера.
