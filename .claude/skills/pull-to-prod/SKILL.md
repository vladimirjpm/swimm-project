# pull-to-prod — затянуть соревнование в прод (Swimm)

Полная инструкция с командами, SQL и footguns — **[`docs/pull-to-prod.md`](../../../docs/pull-to-prod.md)**.
Прочитай её целиком перед началом, а в конце допиши строку в её журнал (§6). Ниже только порядок.

Аргумент — compID isr.org.il (число или ссылка `comp.asp?compID=NNNN`). Просьба Влада
«затяни в прод» и есть разрешение писать в прод-базу на эту задачу; на другое оно не переносится.

## Порядок

1. **Разведка** (§1.2–1.3): файрвол, запись `Sys_DiscoveredCompetitions` (discoveredId, LogligId),
   есть ли уже `Competitions` с этим OrgCompId, дни по стартовому протоколу.
2. **Сухой разбор** (§1.4): `--repull <id> --dry-run --json-out` локально +
   `node server/db/day-json.mjs <json>`. По таблице выбери путь (§0):
   - все дисциплины проплыты, в базе нет → **А** («Затянуть»);
   - есть `0/N` → соревнование идёт → **Б** (по дням, JSON-файлом);
   - уже в базе → **В** (`--repull` / «Перезатянуть»); чемпионат с раундами → **Г** (`--pull-events`).
3. **До записи спроси Влада**, если чего-то не знаешь: длину бассейна, когда превью пишет
   «— не задан —» (не угадывать), путь Б против «подождать конца», странные даты.
4. **ProdAdmin**: `preview_start {name: "swimm-api-prodadmin"}`. **Логинится Влад сам** в панели
   браузера: попроси и дождись «вошёл». Агент пароли и Google-вход не вводит.
5. Импорт по выбранному пути (§2 или §3). Путь Б: после дня 1 — OrgCompId и флаги на Edit
   (Awards — спросить), эстафеты отдельным файлом + `--pull-relays`, места личных строк
   `--pull-places` (секция «כללי» в PDF сквозная через оба пола, И-62), затем сшивка старт-листа
   (§3.4–3.6).
6. **Проверка** (§4): строк = файлу, сверка «сошлось», сайт отдаёт `total`, новых ошибок проверок
   нет, `no-show` только у проплытого. **Погаси ProdAdmin.**
7. Отчёт Владу: comp id, событие, строк, что осталось дотянуть (для пути Б — какие события/дни и
   когда). Запиши строку в журнал §6 инструкции.

## Нельзя

- Запускать путь А на идущем соревновании: будут ложные неявки и все дни одной (последней) датой.
- Оставлять `server/Swimm.API/wwwroot/_tmp-*.json` после загрузки.
- Обходить отказ `--repull` «сначала --split-days».
- Писать в прод SQL без файла в `server/db/private/` и репетиции `local` (правило `prod-sql.mjs`).
