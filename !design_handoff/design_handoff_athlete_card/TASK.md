# Задача: редизайн попап-карточки спортсмена

## Обзор
Полный редизайн карточки спортсмена (открывается из таблицы результатов).
Цели: фото больше не занимает пол-экрана, флаг и логотип клуба хорошо видны,
вся ключевая информация — в один экран без скролла, уровень спортсмена —
единый компонент-дуга по всей карточке.

Эталон — приложенный **`Athlete Card.dc.html`** (открыть в браузере; переключатель
светлой/тёмной темы — проп `theme` / панель Tweaks). Это дизайн-референс,
не код для копирования: реализация — в `client/src/projects/sportsmen-details/sportsmen-details.tsx`
(+ `sportsmen-details.css`), стили — через существующие CSS-переменные, не inline.

## Структура карточки (сверху вниз)

1. **Identity-бар** (фон `--theme-mode-hero-grad`):
   - Фото **76×76**, круглое, бордер 3px акцентным цветом (`--theme-primary`).
   - **Флаг** — значок ~20px на нижне-правом краю фото (absolute, radius 4, тень).
   - Справа (RTL): имя (20px/800), под ним «9 year (2017)» (11px, muted).
   - **Клуб — чип-пилюля**: фон surface, radius 999; логотип клуба **28px на белом
     круге 32px** с окантовкой 2px rgba(акцент, 0.4) + название клуба (12px/700).
     Чип кликабельный (переход на страницу клуба).

2. **Три плитки статистики** (grid 1:1:1, gap 7, radius 12, фон surface):
   контент центрирован по вертикали и горизонтали (flex column, center).
   - **Points** — карьерные очки (20px/800, акцент) + подпись POINTS.
   - **Medals** — три кружка **26px** (золото/серебро/бронза, radial-gradient,
     нулевое значение — opacity 0.4) + подпись MEDALS.
   - **Level** — **компонент-дуга** (см. §Компонент уровня) + подпись LEVEL.
   Подписи: 9px/700, uppercase, letter-spacing 0.05em, muted.

3. **Сегментный переключатель** «{Соревнование} / All-time» — без изменений
   (см. handoff `design_handoff_athlete_alltime`).

4. **Зелёный баннер** очков текущего соревнования — без изменений.

5. **Результаты — строка в 2 линии** (фон surface, radius 14, padding 12):
   - **Линия 1** (flex, center, gap 12):
     колонка «место»: кружок места 34px + под ним «age: N» (10px);
     затем **компонент стиля** — картинка стиля **86px** на белой подложке
     (radius 7, padding 4) с дистанцией поверх (правый верхний угол,
     15px/900, красный #e53935, белая text-shadow);
     время — справа с краю (20px/800, tabular-nums).
   - **Линия 2** (под разделителем 1px `--theme-mode-border`,
     padding-left 46px — выравнивание под компонент стиля):
     слева блок: `Time split: …` (10px, muted; **строка отсутствует, если
     сплитов нет** — ничего не резервировать), `Points: NNN` (11px),
     дата заплыва (10px, muted);
     справа — компонент уровня (дуга, 62×40).

## Компонент уровня (единый для всей карточки)
Полукруглая дуга-датчик: серый трек + акцентная дуга + подпись категории
(«1y», «2y», …) в центре. SVG viewBox `0 0 46 30`, path
`M 6 27 A 17 17 0 1 1 40 27`, stroke-width 4, linecap round; заполнение —
`stroke-dasharray` (доля от 70). Один компонент используется:
- в плитке Level (62×38),
- в каждой строке результата (62×40).
Цвета: трек `--theme-mode-border-input` с прозрачностью, дуга/текст — `--theme-primary`.
Вероятное место: `client/src/projects/components/mix/normative-level-icon` — переиспользовать/расширить.

## Темы
Карточка обязана работать в light/dark (см. `design_handoff_theme_modes/README.md`).
Маппинг, использованный в эталоне:
- фон карточки → `--theme-mode-surface`
- плитки/чипы/строки результатов → `--theme-mode-input-bg`
- hero-градиент → `--theme-mode-hero-grad`
- текст → `--theme-mode-text` / `-secondary` / `-muted`
- разделители → `--theme-mode-border`
- акцент (бордер фото, очки, дуги, активный сегмент) → `--theme-primary`
  (в dark — осветлённый вариант, напр. #2fbf71)
Статусные цвета НЕ зависят от темы: медали, золото категории, красная дистанция
(#e53935), белая подложка иконок стиля и логотипа клуба.

## Данные
Всё из существующих данных спортсмена/результатов; карьерные totals — из
`useAthleteCareer` (см. handoff athlete_alltime). Дата заплыва — из результата.
Флаг — по стране спортсмена; логотип клуба — из данных клуба (в эталоне —
низкокачественные вырезки из скриншота, в приложении использовать оригиналы).

## Fidelity
Hifi: размеры/пропорции элементов, состав и порядок информации, токен-маппинг.
Не hifi: конкретные пиксельные значения теней, «моковые» данные и картинки.
