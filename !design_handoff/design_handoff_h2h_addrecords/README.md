# Handoff: Head-to-Head (H2H) — вкладка Rivals на странице пловца

Живой макет: открой `Canvas.dc.html` из этой папки в браузере (рядом должен лежать `support.js`). Это единственный источник правды по пикселям — при расхождении с текстом ниже верен макет.

## Что в пакете

- `Canvas.dc.html` — утверждённый макет (вариант 1b): compare-шапка, статы, карточки заплывов, состояния выбора.
- `H2H-COMPONENTS.md` — спецификация компонентов (пропсы + точные стили).
- `deep-theme.css` — токены темы Deep (пары dark↔light).
- `assets/style-icon-placeholder.png` — заглушка иконки стиля (в проде — UI_SwimStyle, своя картинка на каждый стиль).
- `assets/avatar-placeholder.png` — заглушка фото пловца.

## Роутинг и данные

- URL: `/swimmers/:id?tab=rivals&rival=:rivalId`. `rival` отсутствует → состояние «выбран только левый» (левый = хозяин страницы). Смена соперника меняет query-param, состояние шарится ссылкой.
- Данные compare: `GET /api/swimmers/{id}/h2h/{rivalId}` (новый эндпоинт). Ответ должен отдавать по каждой паре (стиль, дистанция, бассейн 25/50): лучшие времена обоих + даты, флаги SB/REC, дельту; агрегаты: faster count, season bests count, медали (g/s/b), best FINA pts.
- Favorites: существующий механизм избранного (сердечко), список для попапа — `GET /api/swimmers/{id}/favorites`.
- Все цифры в макете условные (3–2, 7–5, 512–486, медали) — брать из API.

## Структура экрана (сверху вниз)

1. **Compare-шапка**: grid `1fr 200px 1fr` — `H2HMiniCard` (align=left) · «3–2 / faster times» · `H2HMiniCard` (align=right). Карточки зеркальные: фото всегда к центру, сердечко-фаворит во внешнем углу.
2. **Статы** (между hairline-линиями, в столбик): `H2HStatRow` × 4 — season bests, records · all time (три счётчика с `RecordBadge`), medals (`MedalTriple`), best FINA pts. Label по центру на той же сетке, значения прижаты к центру.
3. **Карточки заплывов** `H2HEventCard`: сначала заплывы с результатами у ОБОИХ, orderby стиль → дистанция; затем разделитель «ONLY ONE SWIMMER» и односторонние (пунктир, серая иконка). Внутри карточки — строка на бассейн (25m и/или 50m, обозначение UI_PoolType `--25m--` / `-----50m-----`), победитель — cyan-плашка, бейджи SB/REC.
4. Клик по строке результата → заплыв в `results_main.html` (навигационный контракт в корневом CLAUDE.md).

## Состояния выбора

В макете обе панели показаны инлайн для наглядности; в проде это состояния ОДНОГО экрана:

- **Оба выбраны** → полный compare (пункты 1–3).
- **Выбран один** → `H2HMiniCard` слева, «vs», `H2HEmptySlot` («＋ בחר יריב · choose a rival») справа. Compare не рендерится.
- **Никто не выбран** → два `H2HEmptySlot`.
- Клик по `H2HEmptySlot` → **попап выбора соперника** (в макете НЕ нарисован — сделать в стиле темы): полоса Favorites (чипы `♥ имя`, красные `#f87171`) + поиск «Search a swimmer to compare with...». Выбор подставляет пловца в слот и пишет `rival` в URL.

## Темизация

Хардкод-цвета макета = dark-значения темы Deep. При реализации мапить на токены из `deep-theme.css` (пары light есть). Правила: cyan = быстрее/лидер/«мы»; gold = только медали и НАЦИОНАЛЬНЫЙ рекорд; age/masters-рекорды — серебро (см. §5 в H2H-COMPONENTS.md); красный `#f87171` = favorite. Glow — только у выделенного элемента (сердечко on, плашка победителя — без glow).

## RTL и типографика

- `dir="auto"` на текстовых спанах (имена, клубы), не на контейнерах.
- Времена/цифры: `font-variant-numeric: tabular-nums`.
- Чипы и строка «время+бейдж»: `white-space: nowrap` (иначе переносы на иврите и у бейджей — воспроизводилось).
- Display-шрифт центра («3–2», «vs») — Archivo Black.

Детальные пропсы и пиксельные стили каждого компонента — в `H2H-COMPONENTS.md`.
