# Record wall: спорное время — карточка «Under review» (вариант 13a)

Утверждённый вариант — **13a** (секция 13 в `Competition Overview.dc.html`; 13b и 13c
оставлены для истории, НЕ реализовывать). Заменяет голый значок ⚠ рядом со временем.

## Когда применяется

Рекорд с флагом «время под сомнением» (suspected timing error) — тот же признак,
по которому сейчас рендерится ⚠. Обычные карточки не меняются.

## Анатомия помеченной карточки

```
┌▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨┐  caution-лента 7px (верх)
│ ISR · age 11          ♀ │
│ 50m backstroke · 50M    │
│ 34.08  [⚠ Under review] │  время без изменений + чип
│ מירה מירוסלבה אושקובה   │
│ 20/07/2025              │
└▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨▨┘  caution-лента 7px (низ)
```

- **Caution-лента**: полосы 7px сверху и снизу карточки, CSS-градиент
  `repeating-linear-gradient(-45deg, #f0b429 0 9px, #2a2416 9px 18px)`, `opacity:.9`.
  Никаких картинок/SVG. Карточка получает `overflow:hidden`, вертикальный паддинг
  контента уменьшается на высоту лент (12px → 10px).
- **Чип** «⚠ Under review» рядом со временем: 11px/800, скругление 999px,
  паддинг 3px 10px. Не влезает рядом — переносится под время (`flex-wrap`).
- **Рамка карточки** — янтарная вместо гендерной: `--theme-flag-border`.
  Фон карточки (♀/♂ подложка), время, имя, дата — без изменений.

## Токены

Классы и значения — `record-flag.css`. Добавить в **каждую** тему `client/src/index.css`
(light и dark, парные, контраст ≥ 4.5:1):

- `--theme-flag-text` — текст чипа: `#b45309`
- `--theme-flag-chip-bg` — фон чипа: `rgba(245,158,11,.16)`
- `--theme-flag-chip-border` — рамка чипа: `rgba(245,158,11,.4)`
- `--theme-flag-border` — рамка помеченной карточки: `rgba(240,180,41,.55)`
- `--theme-flag-tape-a` / `--theme-flag-tape-b` — цвета ленты: `#f0b429` / `#2a2416`
  (dark: тот же жёлтый, тёмная полоса светлее фона карточки)

## A11y / текст

- Чип — не интерактивный, но текст обязателен: значок ⚠ один не считывается.
- Формулировка: `Under review` (короткая, в чипе). Полная — для title/aria-label
  карточки: `Suspected timing error. The result is being verified and may be corrected
  or removed.`
- Лента — декоративная (`aria-hidden`), смысл несёт чип.
