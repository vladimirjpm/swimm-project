# Плитка соревнования в шапке (вариант 11c)

Заменяет прежнюю иконку-эмодзи 🏆 64×64 в hero шапки. Утверждённый вариант — **11c**
(секция 11 в `Competition Overview.dc.html`; 11a и 11b оставлены для истории, НЕ реализовывать).

## Анатомия

```
┌──────────┐
│  ❄️ 🏆   │  верхняя полоса: сезон (мелкий) + кубок (крупный), bg surface 92%
│    K     │  буква группы, 28/900, цвет accent-text
│  8-11    │  нижняя лента: возрастная группа, bg surface, text primary
└──────────┘
```

## Правила данных

| Слот | Значение | Когда не рендерится |
| --- | --- | --- |
| Буква | детские группы → **K**, мастерс → **M** | группа не определена — буква пустая, плитка только со значками |
| 🏆 | тип соревнования = чемпионат | обычный старт — кубка нет, в полосе только сезон |
| ❄️ / ☀️ | сезон (зима / лето) из даты или названия | сезон не определён — значка нет |
| Возраст | возрастная группа: `8-11`, `11-14` … | группа не определена — ленты нет, применить `.comp-tile--no-age` |

Значки — эмодзи (как и остальные иконки в проекте), не SVG.

## Размеры

| Класс | Где | Габарит |
| --- | --- | --- |
| `.comp-tile` | десктопная шапка 1b (1440/1920) | 66×80 |
| `.comp-tile--sm` | компактная шапка (мастер-детейл 7a) | 58×70 |
| `.comp-tile--xs` | мобайл < 640px | 52×62 |

## Токены

Все цвета — только через токены из `competition-tile.css`; добавить в **каждую** тему в
`client/src/index.css` (light и dark, парные, контраст ≥ 4.5:1):

- `--theme-comp-tile-bg` — корпус плитки (сейчас accent-text 20%)
- `--theme-comp-tile-border` — рамка (accent-text 35%)
- `--theme-comp-tile-letter` — буква (accent-text)
- `--theme-comp-tile-strip-bg` — полоса значков (surface 92%)
- `--theme-comp-tile-age-bg` / `--theme-comp-tile-age-text` — лента возраста (surface / primary)

Цель та же, что у персональных токенов: перекрасить плитку per-theme без правки компонента.

## Мобильная шапка (фикс)

Секция 10 в прототипе: `10a` — как ломается сейчас, `10b` — как надо. Ниже 640px шапка — колонка:

1. иконка (`.comp-tile--xs`) + заголовок 19px, `flex:1;min-width:0`, `text-wrap:pretty`;
2. мета в 2 строки с `·` и `white-space:nowrap`; бейдж «N Days» — в начале первой строки меты;
3. кнопки `＋ Add media` / `Change ▾` — своя строка, `flex:1`, `min-height:44px`;
4. табы — горизонтальный скролл, `white-space:nowrap`.

На десктопе текстовый блок = `flex:1 1 300px`, кнопки `margin-left:auto` — при сжатии кнопки
переносятся на свою строку, а не сдавливают заголовок в столбик (это и был баг 10a).
