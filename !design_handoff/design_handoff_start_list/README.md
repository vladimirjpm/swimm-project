# design_handoff_start_list — пакет для Клод-кода

Принятый дизайн таба «Start list»: **3a Ticket + Following** (строки заплывов — формат D3).

| Файл | Что это |
|---|---|
| `handoff-to-claude-code.md` | Главный документ: экраны, правила ARRIVE BY, компоненты, данные |
| `start-list-plan.css` | Токены и классы-рецепты: маппинг хардкодов макета → `--theme-personal-*` + Deep-пары |
| `Start List.dc.html` + `support.js` | Живой макет (открыть в браузере). Секция 3a — принятая; 1c/2a ниже — история |
| `swimm-style-icon/*.png` | Эскизные иконки стилей — в коде заменить на существующий `UI_SwimmStyleIcon` |

Контекст: входной хендофф дизайнеру (`design-handoff-start-list-tab.md`, 28.08) — его
раздел 5 («правила, которые нельзя нарушить») действует полностью. Темы: пары
dark↔light по `deep-theme.css` (копия приложена) + личные токены `--theme-personal-*`
из `client/src/index.css`.

Быстрый чеклист реализации:
1. Пикер Following: мульти-чекбоксы фаворитов + тумблер клуба (`/clubs/{id}`), персистенс per-соревнование.
2. Карточка плана: дни-чипы (disabled только если никто не плывёт) → чипы состава → золотой билет (hero + ARRIVE BY + строки D3) → футер Updated/Refresh.
3. ARRIVE BY: разминка из таканона − 30 мин; только чемпионат ∧ залогинен ∧ галочка «I'm coming».
4. Строка D3: плитка времени 74px | UI_SwimmStyleIcon + метка «Girls 9 · H3 · seed» | имена столбиком с дорожками; групповой заплыв — одна строка.
5. Экран «Start list not published yet» с «Notify me» для залогиненного.
6. Share link — шарит состав плана URL-параметрами.
