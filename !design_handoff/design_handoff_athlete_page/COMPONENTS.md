# Что переиспользуем из кода

Правило: **всё, что уже имеет компонент, рисуется этим компонентом.** Верстать заново время,
иконку стиля, дату, уровень и медали — нельзя: они существуют и живут по своим правилам.

## Обязательные к переиспользованию

| сущность | компонент / хелпер | правила |
|---|---|---|
| **время заплыва** | `UI_SwimTime` — `client/src/projects/components/mix/swim-time/swim-time.tsx` | единственный способ вывести время. Он же рисует пометку «время под вопросом». Никакого ручного форматирования `mm:ss.SS` в новых блоках |
| **строка со спорным временем** | `swimFlaggedRowProps` (там же) | возвращает пропсы строки-носителя: caution-лента и рамка. Токены — `--theme-flag-*` в `client/src/index.css`. Правило описано в `client/CLAUDE.md` |
| **иконка стиля + дистанция** | компонент плиты стиля из `sportsmen-details.tsx` (`ResultsTable`, строка ~981) | плита 86×52 на белом, дистанция красным поверх правого верхнего угла с белой обводкой |
| **дуга уровня** | `UI_NormativeLevelIcon` — `components/mix/normative-level-icon` | `viewBox="0 0 46 30"`, дуга `M 6 27 A 17 17 0 1 1 40 27`. Размеры: 62×38 в KPI-плитке, 62×40 в строке результата |
| **медаль с поповером** | `MedalWithTooltip` (`sportsmen-details.tsx`, строка ~37) | тёмный поповер «за что». Кружок 26px в KPI, 38px как место в строке результата |
| **дата** | общий форматтер дат приложения | формат в строке результата — `27 APR 2026`, tabular-nums |
| **бейдж loglig** | `LogligSuggestBadge` (строка ~379) | только залогиненному |
| **гостевой CTA** | `GuestFavoritesCta` (строка ~497) | вместо ♡ / ★ и «My links» |
| **My links** | `MyMediaSection` (строка ~575) | owner-only; в макете добавлена ссылка «Manage in My media →» |
| **лучшие времена** | `AllTimeBests` (строка ~520) | база для таба Results: перестроить на строку-карточку (см. `BLOCKS.md` §6) |

## Что делаем заново

| блок | почему |
|---|---|
| Hero (десктоп) | попап-карточка не рассчитана на страницу: другая сетка `auto / 1fr / KPI` |
| Season carousel | новый общий фильтр страницы; берётся 1:1 со страницы клуба (`design_handoff_club_page/SEASON-CAROUSEL.md`, вариант 4c) |
| Плитки-табы | берутся 1:1 со страницы клуба (`design_handoff_club_page/TABS.md`, вариант 3a folder-tab) |
| Панель Progress | графика истории по стилю/дистанции сейчас нет |

## Переносимость

Все блоки этого пакета — независимые модули: каждый принимает свои данные, не читает глобальный
контекст, кроме выбранного сезона, и не имеет собственных фильтров (исключение — тумблер
25 m / 50 m в PB-таблице). Любой блок должен переноситься на страницу клуба или соревнования
без правок стилей — он использует только токены темы.
