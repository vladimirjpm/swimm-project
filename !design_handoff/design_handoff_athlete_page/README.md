# Swimm — Athlete Page handoff (Deep / Deep Light)

Пакет для реализации публичной страницы спортсмена. Референс-макет — `Athlete Page.dc.html`
(открывать рядом с `support.js`). Актуальный вариант — **2a «Card DNA»**: страница собрана из
блоков существующей попап-карточки `sportsmen-details.tsx` + канон страницы клуба
(сезон-карусель → плитки-табы → панель-«папка»). Ниже в файле лежат более ранние направления
1a (Season desk) и 1b (PB first) — как справочный материал по табам Season и Records & PB.

## Файлы пакета

| файл | что внутри |
|---|---|
| `README.md` | эта карта: модель страницы, темы, правила, навигация |
| `BLOCKS.md` | **главный документ**: спецификация каждого блока — размеры, состояния, контракт данных, интеракции |
| `COMPONENTS.md` | что переиспользовать из кода (время, стиль, дата, уровень, медали) и что писать заново |
| `DATA.md` | контракт API страницы: эндпоинты и формы объектов |
| `theme.css` | токены Deep / Deep Light + классы-рецепты. Единственный источник цветов |
| `record-flag.css` | токены и рецепт «время под вопросом» (уже согласованы на Record wall) |
| `Athlete Page.dc.html` + `support.js` | живой макет (десктоп 1440, мобайл 390, гостевое состояние) |

## Модель страницы

```
Header (глобальная шапка приложения)
Hero — identity
  ├─ аватар 96 (десктоп) / 76 (карточка, мобайл) + флаг страны
  ├─ имя (RTL) · возраст «12 year (2014)» · бейдж рекордов
  ├─ чип клуба (лого на белом круге) → ?tab=clubs&clubId=X
  ├─ зачётная группа · тип программы (🌊 open water)
  ├─ ♡ / ★ + «Suggest loglig profile»     ← только залогиненный
  └─ KPI-плитки: POINTS · MEDALS · LEVEL
Season carousel — кольцевая карусель сезонов + кнопка All   (общая для всей страницы)
Tabs (плитки-«папки»): Season · Results · Records & PB · Progress · Media · History
Panel — содержимое выбранного таба, читает выбранный сезон
```

Один блок фильтров на всю страницу: **сезон** (карусель) выбирается один раз, все табы читают
его. `All` = за карьеру. Сезон = 1 Sep — 31 Aug; внутри сезона два чемпионата ❄ Winter / ☀ Summer,
open water (3/5 km) — один зачёт в сезон, без ❄/☀.

### Что в каком табе

| таб | содержание |
|---|---|
| **Season** | сводка сезона: ❄/☀ карточки (место в группе, очки, заплывы, медали), соревнования сезона, Season shape, «New in NN/NN» |
| **Results** | **только лучшее время на каждую дистанцию** за выбранный сезон (чип `BEST`). Списка «последнее соревнование» здесь нет |
| **Records & PB** | PB-таблица с тумблером 25 m / 50 m и колонками дельты до клубного рекорда и рекорда Израиля по возрасту |
| **Progress** | **история всех заплывов по стилю и дистанции**: выбор дистанции → график времени + список всех попыток. Отдельного таба Compare нет |
| **Media** | «My links» (owner-only управление) + публичная галерея |
| **History** | сезоны и соревнования карьеры |

Правило, действующее во всех списках: **в строке, кроме даты, всегда есть название
соревнования; если это чемпионат — перед названием значок 🏆.**

## Темы

Страница темизируется **только парными токенами**. Фиксированных hex в компонентах быть не должно.
`theme.css` в этом пакете — дизайнерский слой; в проде значения объявляются как `--theme-*`
в `client/src/index.css` для light и dark, переключение — `data-mode` на `<html>`.

Соответствие макета и продовых токенов:

| макет (`theme.css`) | прод (`index.css`) | где |
|---|---|---|
| `--deep-page-bg` | `--theme-mode-bg` | фон страницы |
| `--deep-hero-grad` | `--theme-mode-hero-grad` | шапка |
| `--deep-card-bg` / `-raised` / `-row` | `--theme-mode-surface` / `-input-bg` | карточки, плитки, строки |
| `--deep-card-border` / `-soft` | `--theme-mode-border` | рамки, разделители |
| `--deep-text` / `-mute` / `-faint` / `-ghost` | `--theme-mode-text` / `-secondary` / `-muted` | текст |
| `--deep-accent*` | `--theme-mode-primary*` | акцент, CTA, активный таб, дуга уровня, чип `BEST` |
| `--deep-gold*` | `--theme-mode-gold*` | ★, бейдж рекордов, #1, ☀ summer |
| `--deep-flag-*` | `--theme-flag-*` | время под вопросом (см. `record-flag.css`) |

Темой **не управляются** (одинаковы в light и dark, потому что это физические объекты и знаки):
медальные кружки (золото/серебро/бронза), белая подложка плиты иконки стиля, белый круг под лого
клуба, красная дистанция поверх плиты, флаг страны.

### Правила цвета
- cyan/teal — акцент, CTA, «мы», ❄ winter, дуга уровня, `BEST`;
- gold — медали, ★, рекорды, #1, ☀ summer; больше нигде;
- purple — только open water (3/5 km);
- caution-жёлтый (`--deep-flag-*`) — только «время под вопросом»;
- glow — максимум у одного элемента блока (выбранный таб / текущий сезон).

## Навигация

- клуб → `?tab=clubs&clubId=X`
- строка результата → `results_main.html?competitionId=X&tab=swims&swimmerId=Y&resultId=Z`
- соревнование в Season/History → `results_main.html?competitionId=X&tab=swims&swimmerId=Y`
- «Manage in My media» → страница медиа пользователя

Полный контракт — `NAV-CONTRACT.md` в `design_handoff_competition_overview/`.

## Мобайл 390

Те же блоки одной колонкой. Отличия: аватар 76, KPI-плитки в 3 колонки, табы — нижняя лента
иконка+подпись (48px, активный подчёркнут акцентом), «My links» свёрнут в `<details>`,
все интерактивные элементы ≥ 44px. Состояние сезона общее с десктопом.
