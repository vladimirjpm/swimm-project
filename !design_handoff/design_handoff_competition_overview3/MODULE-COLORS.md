# Цвета модулей Overview — привязка к темам

Цель: цвет каждого модуля Overview (Top clubs, New records, Champions, High Point Award, Media)
задаётся **одним токеном на модуль на тему**. Меняешь 5 hex-значений в теме — перекрашивается вся
мозаика (десктоп 9d/9e/9a и мобайл 9f), включая заливку активной плитки, полосу, медальон, язычок,
заголовки и цифры в большой карточке. Компоненты цветов не знают.

## 1. Базовые токены (то, что ты правишь)

Файл: `client/src/index.css`, добавить в **каждую** тему — light и dark (правило парных токенов).

```css
/* light-вариант темы competition-blue — значения из макета */
--theme-module-clubs:      #0466c8;
--theme-module-records:    #6d28d9;
--theme-module-champions:  #b45309;
--theme-module-hpa:        #0f766e;
--theme-module-media:      #be185d;

/* dark-вариант той же темы: те же оттенки, светлее и менее насыщенные,
   контраст текста на surface ≥ 4.5:1 */
--theme-module-clubs:      #64a8f5;
--theme-module-records:    #a78bfa;
--theme-module-champions:  #e0a256;
--theme-module-hpa:        #4dbfae;
--theme-module-media:      #f472a6;
```

Правила подбора для новой темы:
- **clubs** = как правило `--theme-primary` темы (модуль клубов — «домашний» цвет продукта);
- остальные 4 — равные по светлоте и насыщенности, разнесённые по тону (шаг ≈ 60–70°),
  удобно задавать в `oklch(0.5 0.15 H)` (light) / `oklch(0.75 0.11 H)` (dark) и потом фиксировать hex;
- ♂/♀ цвета (`#1d4ed8` / `#be185d`) — отдельная семантика (пол), НЕ смешивать с цветами модулей;
- золотые персональные токены (`--theme-personal-*`) тоже независимы.

## 2. Производные значения (генерируются, не правятся вручную)

Считаются из базового токена через `color-mix`, поэтому в компонентах нет ни одного hex:

| Назначение | Формула | Где используется |
| --- | --- | --- |
| solid | `var(--m)` | полоса слева 3–4px, залитый медальон, язычок-ромб, метка модуля, цифры-итоги |
| on-solid | `--theme-mode-accent-text` (#fff) | текст/цифра внутри залитого медальона |
| fill (активная плитка) | `color-mix(in srgb, var(--m) 13%, var(--theme-mode-surface))` | подложка активной плитки |
| hover | `color-mix(in srgb, var(--m) 6%, var(--theme-mode-surface))` | ховер неактивной плитки |
| chip / медальон неактивный | `color-mix(in srgb, var(--m) 12%, var(--theme-mode-surface))` | круг медальона, пилюли-бейджи |
| hairline | `color-mix(in srgb, var(--m) 20%, var(--theme-mode-surface))` | границы вложенных блоков в карточке |
| logo-stripes | `color-mix(24%)` / `color-mix(8%)` | полосатый плейсхолдер лого клуба |

CSS-реализация — `module-colors.css` в этой папке (готов к копированию, Tailwind v4 `@theme` включён).

## 3. Карта модуль → токен

| Модуль Overview | Токен | Итог на плитке (мобайл/десктоп) |
| --- | --- | --- |
| Top clubs | `--theme-module-clubs` | лого клуба-лидера + имя + «рейтинг · N клубов» |
| New records | `--theme-module-records` | число рекордов у лидера + имя + «N рекордов у M пловцов» |
| Champions | `--theme-module-champions` | максимум очков + имя + «макс. очков · ♂/♀» |
| High Point Award | `--theme-module-hpa` | возрастная группа (8–11) + «N наград» + «каждый возраст · ♂ / ♀» |
| Media | `--theme-module-media` | количество файлов + «N видео · M фото» |

## 4. Состояния плитки (одинаково на десктопе и в мобайле)

```
неактивная: surface + полоса 3px solid(m) + медальон chip(m) + метка solid(m)
ховер:      hover(m)
активная:   fill(m) + полоса 4px solid(m) на всю высоту
            + медальон solid(m) с белой цифрой/лого
            + ромб-«язычок» solid(m): десктоп — справа (указывает на карточку),
              мобайл — снизу по центру (указывает на карточку под плиткой)
большая карточка: surface, кромка 3px solid(m) слева (десктоп) / шапка solid(m) (лейны 9b/9c),
            заголовок и все итоговые цифры — solid(m)
```

## 5. Проверка после смены цветов

1. Контраст `solid(m)` на `surface` ≥ 4.5:1 (метки, цифры) — и в light, и в dark.
2. Белый текст на `solid(m)` (медальон) ≥ 4.5:1 — если базовый цвет светлее ~55% L,
   в медальоне использовать `--theme-mode-text` вместо белого.
3. 5 цветов различимы при дейтеранопии (проверить симулятором): шаг тона ≥ 60°.
4. Активная плитка отличается от неактивной не только цветом (полоса 4px + залитый медальон + язычок) —
   доступность не зависит от цвета.
