# Задача: карточка спортсмена — переключатель «Соревнование / All-time»

## Что добавить
В попап-карточке спортсмена (открывается из таблицы результатов) появляется переключение между данными текущего соревнования и общими карьерными данными.

Эталонная реализация — в приложенном `Competition Results.dc.html` (искать по комментариям `scope switcher`, `scope banner`, `all-time section`). Скриншоты состояний не нужны — структура ниже.

## Структура карточки (сверху вниз)

1. **Шапка (hero)** — аватар, флаг, уровень (MSMK), клуб, очки и медали.
   ВСЕГДА показывает ОБЩИЕ карьерные данные спортсмена (totalPoints, gold/silver/bronze за всё время), независимо от выбранного режима.

2. **Полоса с именем** — без изменений.

3. **Сегментный переключатель** (под именем) — 2 сегмента:
   - «{Название соревнования}» + подпись с датой, напр. «Hedera Meet / Jun 2026»
   - «All-time» + подпись «career stats»
   Активный сегмент — заливка акцентным цветом темы, белый текст. Стиль: контейнер surface-фон, 1px бордер, radius 12, внутри сегменты radius 9.
   При открытии карточки режим всегда сбрасывается на «соревнование».

4. **Зелёный баннер** (градиент акцентной темы, radius 14) — есть в ОБОИХ режимах, чтобы попап не «прыгал» по высоте:
   - Режим «соревнование»: слева очки за ЭТО соревнование (крупно, «NNNpt»), подпись «this competition · …»; справа три медальных кружка (золото/серебро/бронза за это соревнование).
   - Режим «All-time»: слева число соревнований (крупно) + подпись «competitions»; справа число заплывов (крупно) + подпись «races». (Позже могут добавиться ещё метрики.)

5. **Контент**:
   - Режим «соревнование»: текущий список результатов (как сейчас, без изменений).
   - Режим «All-time»: секция «Best times by style» — карточка на каждый стиль:
     - слева бейдж 44×44 (radius 12, светлый акцентный фон): дистанция крупно + короткий код стиля (FR/BK/BR/FLY/IM);
     - в центре: время (18px, tabular-nums) и строка «50m Free · 50m pool»;
     - справа: «Points: NNN» и где/когда показано («Israel Winter Cup · Dec 2025»).

## Данные

Карьерные данные загружаются отдельно от результатов соревнования (fetch при монтировании, с fallback). Формат — см. приложенный `athlete-career-sample.json`:

```
{
  "<имя спортсмена>": {
    "competitions": 9,      // всего соревнований
    "races": 34,            // всего заплывов
    "since": 2022,
    "totalPoints": 2846,
    "gold": 4, "silver": 6, "bronze": 3,
    "bestByStyle": [
      { "stroke": "Free", "distance": "50", "time": "00:27.90",
        "points": 361, "pool": "50m",
        "competition": "Israel Winter Cup", "date": "Dec 2025" }
    ]
  }
}
```

Если данных по спортсмену нет — показать плейсхолдеры («—»), не ломать карточку.

## Темы
Все цвета — через существующие токены темы (акцент main/light/grad, surface, border, text*). Работает в светлой и тёмной теме, и в режимах training/competition-акцента.
