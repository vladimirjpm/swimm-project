# Handoff: фильтр Position в полосе выбранных фильтров

## Overview

На странице результатов над таблицей есть полоса выбранных фильтров (`results-filtered-info.tsx`) — сейчас пять колонок: Date, Club, Event, Age, Pool. Нужно показать в ней шестой фильтр — **Position** (`position_filter`: `all | top | podium`), не сломав мобайл.

Решение состоит из двух частей:

1. **Десктоп** — Position становится шестой равноправной колонкой полосы.
2. **Мобайл (< 768px)** — полоса перестраивается в две строки: сверху мелко всё, что в состоянии «All», снизу крупно и по центру выбранные фильтры. Выбранный фильтр физически исчезает из верхней строки и появляется в нижней.

Дополнительно вводится общее правило, действующее на обоих брейкпоинтах: **колонка в состоянии «All» не занимает полноценное место**. На десктопе это даёт запас ширины под шестую колонку, на мобайле — возможность уместить все неактивные фильтры в один узкий ряд.

## About the Design Files

Файлы в этом бандле — **дизайн-референс, сделанный в HTML**. Это прототип, показывающий вёрстку, состояния и поведение; это не production-код для копирования. Задача — воспроизвести показанное в существующем React-коде проекта (`client/src/projects/results-table/`), пользуясь его текущими компонентами, Tailwind-классами и токенами тем из `client/src/index.css`.

`Results Filter Bar.dc.html` открывается прямо в браузере. Первый мобильный макет в секции 2b — интерактивный: клик по чипу переносит его между строками, повторные клики по Position прокручивают три значения фильтра.

## Fidelity

**High-fidelity.** Цвета, размеры шрифтов, отступы и радиусы в макете — конечные значения, их можно брать напрямую. Единственное исключение: логотипы клубов, флаги стилей и аватары показаны штриховыми плейсхолдерами — в приложении на их местах остаются существующие реальные изображения.

## Источник правды по значениям Position

Подписи значений **не выдумываются заново** — они берутся из уже существующего `POSITION_OPTIONS` в `client/src/projects/components/filter-section/filter-position-buttons.tsx`:

| value | label | В полосе |
|---|---|---|
| `all` | `All` | колонка не активна (см. правило «All») |
| `top` | `Top 10` (`Top ${TOP_N_POSITIONS}`) | синий активный чип |
| `podium` | `🥇🥈🥉 1-2-3` | золотой активный чип |

Один словарь на сайдбар и на полосу. Если `TOP_N_POSITIONS` изменится, подпись в полосе меняется автоматически.

Важная особенность: дефолт `position_filter` — `top`, а не `all` (см. `results-table.tsx`). То есть Position активен почти всегда, в отличие от остальных фильтров, которые по умолчанию пустые. Это и есть причина, по которой его надо показывать: он единственный молча урезает выдачу.

## Screens / Views

### 1. Десктоп — полоса выбранных фильтров (≥ 768px)

**Purpose:** одним взглядом ответить, какая выборка сейчас на экране.

**Layout:** горизонтальный ряд колонок, контейнер по центру, `background: #fff`, `border: 1px solid #e6e8ee`, `border-radius: 14px`, `padding: 16px 8px`, `box-shadow: 0 1px 2px rgba(16,24,40,.05)`.

**Колонка (общий вид):**
- `display:flex; flex-direction:column; align-items:center; gap:8px`
- `padding: 0 20px`, `min-width: 132px`
- разделитель между колонками: `border-right: 1px solid #e6e8ee` (у последней колонки нет)
- заголовок: 11px / 800 / `letter-spacing:.8px` / `text-transform:uppercase` / `#8a8f9c`

**Колонка Position (отличия):**
- `padding: 6px 20px`, `border-radius: 10px`, разделителя нет
- `top`: фон `#eef4fd`, рамка `1px solid rgba(4,102,200,.22)`, значение 19px / 800 / `#0466c8` / `white-space: nowrap`
- `podium`: фон `rgba(212,175,55,.14)`, рамка `1px solid rgba(212,175,55,.45)`, значение — медали 19px (`line-height:1.2`) плюс `1-2-3` 11px / 900 / `#8a6d1a`
- `all`: колонка не рендерится

Максимум шести колонок по 132px + отступы укладывается в рабочую ширину без переносов; типовой случай — две-три колонки.

### 2. Мобайл — полоса в две строки (< 768px)

Контейнер: `background:#fff; border:1px solid #e6e8ee; border-radius:12px; padding:8px; display:flex; flex-direction:column; gap:8px`.

**Строка 1 — «доступно» (все фильтры со значением All):**
- `display:flex; gap:4px`, без переноса (`flex-wrap: nowrap`)
- каждый чип: `flex: 1 1 0; min-width: 0`, `padding: 5px 2px`, `border-radius: 8px`, фон `#f7f8fa`, рамка `1px solid #edeff3`
- подпись: 8.5px / 800 / uppercase / `letter-spacing:.3px` / `#a2a8b4`; **сокращённая** (`Position` → `Pos`)
- значение: 10.5px / 700 / `#8a8f9c`, текст `All`
- подпись и значение: `white-space:nowrap; overflow:hidden; text-overflow:ellipsis; max-width:100%`
- шесть чипов при 390px дают ~59px на чип — влезают; по мере ухода фильтров вниз оставшимся автоматически достаётся больше ширины

**Строка 2 — «выбрано»:**
- `display:flex; justify-content:center; flex-wrap:wrap; gap:8px`
- отбивка сверху: `border-top: 1px dashed #e6e8ee; padding-top: 9px`
- чип: ширина по контенту, `padding: 7px 14px`, `border-radius:10px`, фон `#eef4fd`, рамка `1px solid rgba(4,102,200,.24)`
- подпись: 9.5px / 800 / uppercase / `letter-spacing:.6px` / `#8a8f9c`, **полная** (`Position`)
- значение: 16px / 800 / `#0466c8` / `line-height:1.2` / `nowrap`; для Date / Club / Event вместо текста — та же графика, что на десктопе, но мельче (плашка даты шириной 54px, флаг стиля 36×17, логотип клуба 22px)
- Position в `podium`: фон `rgba(212,175,55,.14)`, рамка `rgba(212,175,55,.45)`, медали 13px + `1-2-3` 11px / 900 / `#8a6d1a`

**Состояния:**
- ничего не выбрано → строка 2 **не рендерится вообще** (не пустой блок, не нулевая высота): полоса ровно в одну строку
- выбран один → в строке 2 один центрированный чип, в строке 1 остальные пять
- выбраны все шесть → строка 1 не рендерится, строка 2 переносится по `flex-wrap` в две-три линии

## Interactions & Behavior

- Чип в любой из строк кликабелен и ведёт себя как соответствующий контрол сайдбара (открывает тот же выбор значения). Для Position попап не нужен: значений три, клик прокручивает `all → top → podium → all`.
- Переход фильтра между строками — следствие изменения `position_filter` / прочих фильтров в сторе, отдельного локального состояния у полосы нет.
- Ширина чипов верхней строки меняется сама (`flex: 1 1 0`), анимировать не обязательно; если добавляете переход, ограничьтесь `transition: flex-basis .15s ease`.
- Hover на чипе: верхняя строка `#f7f8fa → #eef0f4`, нижняя `#eef4fd → #e2ecfb`.
- Полоса не скроллится горизонтально ни на одном брейкпоинте.

## State Management

Новое состояние не заводится. Всё берётся из уже существующего `state.filterSelected`:

- `position_filter: 'all' | 'top' | 'podium'` (дефолт `top`)
- разделение чипов по строкам — производная: активен фильтр или нет
- флаги `show*` в `results-table.tsx` перестают управлять только содержимым ячейки и становятся условием рендера колонки целиком

Правило «активности» по фильтрам: `position_filter !== 'all'`; для остальных — значение выбрано (не пустое / не «все»).

## Порядок и переполнение

Порядок фильтров фиксированный: **Position · Event · Age · Date · Club · Pool · Level · Gender · Category**. Position идёт первым как единственный, кто урезает выдачу неявно.

Если активных фильтров становится больше, чем влезает (на десктопе — больше семи), последние сворачиваются в чип **«+N filters»**: `border: 1px dashed #cfd5df`, фон `#f4f6f9`, число 15px / 900 / `#5b6470`, подпись `filters` 9.5px / 800 / uppercase / `#8a8f9c`; клик открывает поповер со списком. На мобайле тот же чип занимает место в верхней строке.

Собственных ассетов нет.
