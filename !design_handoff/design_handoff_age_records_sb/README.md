# Handoff: карточка ISR Age Records — мобильная ячейка и таб Season best

## Overview

Карточка `NormativeAgeRecords` (`client/src/projects/results-table/components/normative-age-records.tsx`) показывает рекорды Израиля по возрастам над таблицей результатов. Таблицу внутри рисует общий компонент `UI_GenderAgeTable` (`client/src/projects/components/mix/gender-age-table/gender-age-table.tsx`), которым пользуются также High Point Award и ISR Masters Records.

Две задачи:

1. **Мобайл.** Когда в таблице есть обе гендерные колонки, ячейка слишком узкая: имя и клуб обрезаются многоточием, время прижимается к тексту вплотную. Ячейка перестраивается в столбик — время первой строкой, под ним имя / клуб / дата.
2. **Season best.** Если для выбранной дистанции есть лучшее время сезона, заголовок карточки превращается в два таба: **ISR Age Records** и **Season best**. Открыт всегда один; свёрнутый таб показывает только лучшее время ♂ и ♀ — без имени, клуба и даты.

## About the Design Files

`Age Records.dc.html` — **дизайн-референс в HTML**, открывается прямо в браузере. Это прототип вёрстки и поведения, не production-код. Реализовать нужно в существующих React-компонентах проекта, их Tailwind-классами и токенами тем из `client/src/index.css`.

Секции в файле сверху вниз:

- **2a** — табы ISR Age Records ↔ Season best (мобайл 375 + десктоп ≥640). Табы кликабельны; параметры `hasSeasonBest` и `activeTab` вынесены в Tweaks.
- **1a** — мобильная ячейка в столбик: три фрейма «сейчас» / «предложение» / десктоп без изменений.

## Fidelity

**High-fidelity.** Цвета, размеры шрифтов, отступы и радиусы — конечные значения, взяты из текущего кода `gender-age-table.tsx` и могут применяться напрямую. Имена, клубы и времена в макете — демо-данные. Тёмная тема в макете не показана: у всех цветов ниже уже есть dark-пары в `GENDER` внутри `gender-age-table.tsx`, их и используйте.

## 1. Мобайл: ячейка в столбик (секция 1a)

**Правило включения:** ширина `< 640px` (брейкпоинт `sm`, уже есть хук `useIsSmUp()` в `gender-age-table.tsx`) **и** в таблице показаны обе колонки — `showMale && showFemale`. Если гендер один, ячейка получает всю ширину и остаётся строчной, как сейчас.

**Ячейка (`Cell`) в режиме столбика:**

- `display:flex; flex-direction:column; gap:1px`, `border-radius:8px`, `padding:7px 10px`
- мужская — `align-items:flex-start`, фон `#eaf2fd`; женская — `align-items:flex-end; text-align:right`, фон `#fdeff5`
- порядок строк одинаковый для обоих полов: **время → имя → клуб → дата** (в строчном режиме порядок остаётся зеркальным, как сейчас)
- время: 16px / 800 / `line-height:1.15` / `tabular-nums`, цвет `#1e6fd6` (м) и `#d6417f` (ж) — на 1px крупнее строчного мобильного варианта
- имя: 11.5px / 700, `#123a70` (м) / `#7a1f4b` (ж), `line-height:1.25`
- клуб: 10px / `#8a93a3`
- дата: 9px / `#aab0bd` / `tabular-nums` (рендерится тем же `UI_DateIcon`, если `showDate`)
- обрезка многоточием снимается: текст переносится, ячейка растёт по высоте

**Сетка:** колонка возраста на мобиле ужимается до **34px** (сейчас `ageColWidth={52}` прокидывается из `normative-age-records.tsx` на оба брейкпоинта). У `UI_GenderAgeTable` уже есть проп `ageColWidthMobile` — задать `ageColWidthMobile={34}`. Значение возраста выравнивается по центру ячейки по вертикали (`align-items:center` в самой ячейке, а не у грида — строки стали высокими).

Зазоры сетки на мобиле: `column-gap:6px`, `row-gap:6px`.

**Ничья (несколько награждённых в ячейке):** правило не меняется — на узком экране записи идут в столбик друг под другом, значение печатается один раз, как сейчас.

## 2. Табы ISR Age Records / Season best (секция 2a)

**Параметры компонента:**

| Параметр | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `hasSeasonBest` | `boolean` | — (есть данные season best или нет) | `false` → панель табов не рендерится, карточка остаётся такой же, как сейчас: `🏅 ISR Age Records` в заголовке |
| `activeTab` | `'records' \| 'season'` | `'records'` | какой таб открыт |

`activeTab` — управляемый параметр: приходит снаружи (URL / стор), клик по табу его меняет. В макете это Tweaks-параметр, клик по табу переключает локально.

**Панель табов:**

- контейнер: `display:flex; gap:4px` (мобайл) / `6px` (десктоп), фон `#f4f6fa`, `border-radius:12px`, `padding:4px`
- мобайл — табы `flex:1` (половина ширины каждый); десктоп — `flex:none; white-space:nowrap`, панель по контенту (`width:fit-content`)
- активный таб: фон `#ffffff`, `border-radius:9px`, `box-shadow:0 1px 2px rgba(20,28,45,.10)`, текст `#1a1a1a`
- неактивный: фон прозрачный, текст `#8a93a3`
- `padding:7px 12px`, подпись 12px / 800 (мобайл) и 14px / 800 (десктоп)
- подписи: `🏅 ISR Age Records` и `⏱ Season best` (на десктопе — `Season best 2025/26`, сезон подставляется)

**Свёрнутый таб — только времена:**

- два значения через точечный разделитель `·` (`#c9cfd9`), `tabular-nums`
- мужское `#1e6fd6`, женское `#d6417f`, 11.5px / 800 (мобайл) и 13px / 800 (десктоп)
- ни имени, ни клуба, ни даты, ни возраста
- мобайл: времена под подписью таба, по центру, `margin-top:3px`; десктоп: в одну строку с подписью, `gap:7px`
- если для одного из полов данных нет — показывается одно время, разделитель не рендерится

**Открытый таб** рендерит обычную таблицу `UI_GenderAgeTable` — ту же, что и раньше, с теми же колонками `♂ MAN | AGE | ♀ WOMAN`. Отступ от панели табов до шапки таблицы: 12px (мобайл) / 16px (десктоп).

**Открыто ↔ свёрнуто:** тап по любому месту неактивного таба открывает его; активный таб по тапу не сворачивается — всегда открыт ровно один. Прежнее поведение «тап по заголовку сворачивает всю карточку» при `hasSeasonBest === true` не используется; при `hasSeasonBest === false` остаётся как есть (включая подсказку `ⓘ Tap the header to collapse`).

**Открытый вопрос:** свёрнутое время в макете — лучшее по всей таблице среди показанных возрастов. Если для страницы правильнее время конкретного возраста (когда выбран год рождения) — берите его, разметка та же.
