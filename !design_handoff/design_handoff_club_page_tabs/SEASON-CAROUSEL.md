# Season filter — кольцевая карусель (вариант 4c)

Утверждённый вариант — **4c** (секция 4 в `Club Page.dc.html`; 4a/4b — история, не
реализовывать). Заменяет ряд пилюль сезонов в полосе SEASON над табами (см. TABS.md —
позиция полосы не меняется: между шапкой клуба и табами, действует на все табы).

## Поведение — это КАРУСЕЛЬ (season wheel)

- Лента сезонов **закольцована** и отсортирована хронологически: `10/11 … 25/26 → 10/11 …`.
- Выбранный (current) сезон — **всегда строго по центру**. Никогда не смещается.
- Соседи распределены **равномерно**: desktop — по 3 с каждой стороны, mobile — по 1.
  Старые продолжаются влево, новые вправо; за краем ленты — wrap (после 25/26 идёт 10/11),
  поэтому слоты всегда заполнены.
- Переключение:
  - клик/тап по любому видимому соседу → он «подъезжает» в центр (slide-анимация
    ~200ms ease-out, весь ряд едет);
  - кнопки ‹ › → шаг на один сезон (‹ старее, › новее);
  - на тач-экранах свайп по полосе = шаг.
- Слоты фиксированной ширины (desktop 52px, mobile 44px), чтобы ряд не дёргался
  при смене цифр; `font-variant-numeric: tabular-nums`.

## Состояние All

- Кнопка **All** слева; справа — пустой спейсер той же ширины (desktop 64px,
  mobile 52px), чтобы центр карусели был строго по центру полосы.
- All активен: заливка `rgba(34,211,238,.14)` + рамка `rgba(34,211,238,.5)` + текст cyan,
  а с центрального сезона подсветка **снимается** — текст `rgba(255,255,255,.75)`,
  без text-shadow. Cyan-glow в полосе всегда ровно у одного элемента: сезон ИЛИ All
  (правило Deep: glow только у выбранного).
- Любой шаг/тап по карусели снимает All и возвращает подсветку центральному сезону.

## Размеры и стили (Deep, всё из существующих токенов theme.css)

Полоса: bg `rgba(0,0,0,.16)`, border-top `1px solid rgba(34,211,238,.14)`,
паддинг desktop `11px 22px`, mobile `9px 14px`.

| Сосед ±1 | 15px, `rgba(255,255,255,.65)` | 13px, `rgba(255,255,255,.42)` |

Все цвета — из Deep-темы (`deep-theme.css` пары dark↔light): cyan-акцент #22d3ee и его
альфы, стекло white/.05, никаких новых токенов. В Deep Light — те же роли из light-пары.

## A11y

- Карусель — `role="listbox"`-подобный контрол: центр `aria-current`, соседи — кнопки
  с полным названием сезона в `aria-label` («Season 23/24»).
- ‹ › — настоящие `<button>`; hit-target ≥44px (добить прозрачным паддингом).
- `prefers-reduced-motion: reduce` → без slide-анимации, мгновенная смена.
