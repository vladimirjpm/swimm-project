# Swimm — Club Page handoff (Deep / Deep Light)

Пакет для реализации страницы клуба. Референс-макет: `Club Page.dc.html` (вариант **1b Deep** — выбранный; секция «Deep Light» — та же страница в светлой теме; открывать рядом с `support.js`).

## Файлы
- `theme.css` — токены обеих тем + классы-рецепты. Единственный источник цветов; применим к любой странице (клуб, атлет, competition overview).
- `CARDS.md` — спецификация каждой карточки: назначение, контракт данных, интеракции. Карточки независимы — страница собирается из них как из блоков.
- `Club Page.dc.html` + `support.js` — живой макет.

## Модель страницы
```
Hero (клуб, лого, KPI, Follow)
Global filters  ← один блок фильтров на ВСЮ страницу
  ├─ Season: All + список сезонов (20+ → горизонтальный свайп-ряд)
  └─ Group:  All + плитки зачётных групп: K 8–11 · Y 11–14 · N נוער · B בוגרים · M Masters · 🌊 3km · 🌊 5km
Cards (каждая читает выбранный scope, своих фильтров не имеет,
       исключение — локальный переключатель пула у Record Wall)
```
- Сезон = 1 Sep–31 Aug; в сезоне 2 чемпионата: ❄ Winter + ☀ Summer (для обычных групп). Open water (3/5 km) — один зачёт в сезон, без ❄/☀.
- Ранги сравнимы между соревнованиями, очки — нет (у каждого свои правила). В графиках всегда подписывайте ранги.
- `gridSeasons` — параметр «сколько сезонов показывает грид при Season=All» (default 3).
- Мобайл 390: те же карточки одной колонкой, фильтры — свайп-ряды; состояние фильтров общее с десктопом.

## Правила цвета (см. theme.css)
- cyan/teal — акцент, CTA, «мы» в таблицах, ❄ winter;
- gold — медали, ранг #1, ☀ summer; больше нигде;
- purple — только open water (3/5 km);
- glow — максимум у одного элемента карточки (выбранный/текущий);
- male/female (голубой/розовый) — только аватары и ♂/♀ бейджи.

## Навигация
- Клуб в standings → страница клуба `?tab=clubs&clubId=X`.
- Пловец (swimmers, record wall) → страница пловца.
- Соревнование в timeline → `results_main.html?competitionId=X&tab=swims`.
Полный контракт — `NAV-CONTRACT.md` в `design_handoff_competition_overview/`.
