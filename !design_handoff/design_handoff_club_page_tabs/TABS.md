# Club Page: табы (вариант 3a, folder-tab)

Утверждённый вариант — **3a** (секция 3 в `Club Page.dc.html`). Карточки страницы клуба
группируются в 5 табов под шапкой клуба.

Порядок блоков сверху вниз: шапка клуба → **полоса SEASON-карусели** (общий фильтр,
см. SEASON-CAROUSEL.md — действует на ВСЕ табы) → плитки-табы → панель контента,
сросшаяся с активной плиткой («папка», см. ниже).

## Табы и содержимое

| Таб | Иконка | Подпись-сводка (desktop) | Содержимое |
| --- | --- | --- | --- |
| Season | ▦ | `grid · standings` | глобальный фильтр сезонов + SEASON × GROUP GRID + STANDINGS |
| Records | ⏱ | `21 · best season` | рекорды клуба + BEST SEASON |
| Swimmers | 🏊 | `142 · coaches` | состав + карточка тренеров |
| Media | ▶ | `36 items` | фото/видео |
| History | 🗓 | `87 competitions` | Competition history |

Счётчики в подписях — живые данные, не хардкод.

## Desktop (≥640px)

Плитки-табы в стиле групповых плиток hero deck (2b), на подложке `rgba(0,0,0,.28)`,
грид `repeat(5,1fr)`, gap 8px, паддинг `12px 14px 0` (снизу 0 — активная плитка
срастается с панелью):

- Плитка: radius 13px, паддинг 11px 13px; строка 1 — круг-иконка 24px + имя
  Archivo Black 12px letter-spacing .04em; строка 2 — подпись 10.5px/800.
- Неактивная: bg `rgba(255,255,255,.04)`, border `rgba(255,255,255,.09)`,
  текст/иконка `rgba(255,255,255,.75)`, подпись `.4`.
- **Активная — «папка», срастается с панелью контента:**
  - плитка: solid bg `#0c2a3f`, border `1px solid rgba(34,211,238,.5)`,
    `border-bottom:none`, radius `13px 13px 0 0`, `margin-bottom:-1px`,
    `position:relative; z-index:1`, glow `0 -6px 18px rgba(34,211,238,.18)`;
    круг иконки залит cyan (#22d3ee, глиф #04182b), имя cyan.
  - панель: тот же bg `#0c2a3f`, та же рамка cyan .5, radius `0 13px 13px 13px`
    (верхний угол под активной плиткой прямой; если активная не первая — оба верхних
    угла 13px, кроме зоны стыка), `margin:0 14px 14px`,
    shadow `0 0 18px rgba(34,211,238,.14)`. Внутри — контент активного таба.
  - визуально плитка и панель — одно целое: общий фон, общая рамка, без шва
    (панельный border-top перекрыт плиткой за счёт -1px и z-index).
  Glow — только у активной (правило темы).

## Mobile (<640px)

Грид `repeat(5,1fr)` на той же подложке, без счётчиков:

- Колонка: иконка 17px + подпись 9.5px/800, min-height 48px, вертикальный паддинг 7-8px.
- Активная: cyan + underline 2.5px (border-bottom) + text-shadow glow; остальные
  `rgba(255,255,255,.6)`.
- Влезает в 390px без скролла.

## Фильтр сезонов — НАД табами, общий

Фильтр сезонов НЕ живёт внутри таба Season: это полоса-карусель между шапкой клуба
и табами (bg `rgba(0,0,0,.16)`, border-top `rgba(34,211,238,.14)`), одна на страницу,
действует на все табы (Season, Records, History…). Полная спека — `SEASON-CAROUSEL.md`.

## Токены (Deep, см. theme.css)

Всё из существующих: cyan-акцент `#22d3ee` и его альфы (.14 бг, .5 бордер),

## A11y

Табы — `role="tablist"`/`role="tab"` + `aria-selected`; иконки декоративные
(`aria-hidden`), имя таба — текст. Hit-target мобильного таба ≥48px.
