🛠️ Helpers Documentation

Документация по хелперам проекта Swimm

⚠️ Этот файл только для разработки. Не включается в production build.
Расположение: src/utils/helpers/

📁 Структура файлов

helpers/
├── index.ts              # Единая точка входа (реэкспорт всех хелперов)
├── helper-time.ts        # HelperTime — работа со временем
├── helper-gender.ts      # HelperGender — пол и CSS классы
├── helper-normative.ts   # HelperNormative — нормативы и уровни
├── helper-results.ts     # HelperResults — группировка/сортировка результатов
├── helper-swimmer.ts     # HelperSwimmer — статистика спортсмена
├── helper-club.ts        # HelperClub — статистика по клубам
├── club-points-helper.ts # ClubPointsHelper — расчёт очков клуба
└── data-helper.ts        # Helper — фасад для обратной совместимости (deprecated)
⏱️

HelperTime

Работа со временем: парсинг и форматирование

helper-time.ts
parseTimeToSeconds(time) static
Парсит строку времени в секунды. Поддерживает форматы "MM:SS.ms" и "SS.ms"
static parseTimeToSeconds(time: string | number): number
// "1:23.45" → 83.45
formatSecondsToTimeString(totalSeconds) static
Форматирует секунды в строку времени
static formatSecondsToTimeString(totalSeconds: number): string
// 83.45 → "1:23.45"
⚧️

HelperGender

Работа с полом: нормализация и CSS стили

helper-gender.ts
resolveGender(gender) static
Нормализует значение пола из различных форматов
static resolveGender(gender: unknown): 'male' | 'female' | 'none'
// "f", "female", "w" → "female"
// "m", "male" → "male"
getGenderBgClass(gender) static
Возвращает Tailwind CSS класс фона в зависимости от пола
static getGenderBgClass(gender: string): string
// "female" → "bg-pink-100"
// "male" → "bg-blue-100"
🏅

HelperNormative

Расчёт нормативов и уровней спортсменов

helper-normative.ts
resolvePoolType(poolType) static
Нормализует тип бассейна
static resolvePoolType(poolType: unknown): '25m_pool' | '50m_pool'
// "25", "25m" → "25m_pool"
// "50", "50m" → "50m_pool"
getNormativeLevelInfo({...}) static
Вычисляет уровень норматива для результата. Поддерживает обычные и мастерские нормативы.
static getNormativeLevelInfo({
gender: Gender,
poolType: PoolType,
styleName: string,
distance: string,
time: number,
isMaster?: boolean,
event_style_age?: string | null
}): NormativeLevelInfo
// Возвращает: { currentLevel, nextLevel, progressToNextLevel, ... }
📊

HelperResults

Группировка и сортировка результатов соревнований

helper-results.ts
sortByTime(arr) static
Сортирует массив результатов по времени (от лучшего к худшему)
static sortByTime(arr: Result[]): Result[]
showTrainingTable(results) static
Создаёт плоскую таблицу: одна группа со всеми элементами
static showTrainingTable(results: Result[]): TrainingGroup[]
groupTrainingByName(results) static
Группирует результаты по имени спортсмена + дате, сортирует по set/order
static groupTrainingByName(results: Result[]): TrainingGroup[]
groupTrainingBySet(results) static
Группирует результаты по номеру сета + дате, сортирует по order → time → name
static groupTrainingBySet(results: Result[]): TrainingGroup[]
getDolphinDataByName(data, name) static
Фильтрует данные по имени спортсмена
static getDolphinDataByName(data: Result[], name: string): Result[]
getDolphinDataGroupedByDate(data) static
Группирует данные по дате с сортировкой по времени внутри каждой группы
static getDolphinDataGroupedByDate(data: Result[]): Record<string, Result[]>

HelperSwimmer

Статистика спортсмена: медали, очки, лучшие результаты

helper-swimmer.ts
getBestResultsByStyle(results, selectedName) static
Получает лучшие результаты спортсмена по каждому стилю плавания. Учитывает эстафеты.
static getBestResultsByStyle(results: Result[], selectedName: string): Array<Result & { levelInfo: NormativeLevelInfo }>
getMedalCountsByName(results, selectedName) static
Подсчитывает медали спортсмена (1, 2, 3 места)
static getMedalCountsByName(results: Result[], selectedName: string): { first: Result[], second: Result[], third: Result[] }
getInternationalPointsSumByName(results, selectedName) static
Суммирует международные очки спортсмена
static getInternationalPointsSumByName(results: Result[], selectedName: string): number

📖 Примеры использования

Новый способ (рекомендуется)

// Импорт конкретных хелперов import { HelperTime, HelperNormative, HelperSwimmer } from '../utils/helpers'; // Использование const seconds = HelperTime.parseTimeToSeconds("1:23.45"); const levelInfo = HelperNormative.getNormativeLevelInfo({ ... }); const bestResults = HelperSwimmer.getBestResultsByStyle(results, name);

Старый способ (для обратной совместимости)

// Импорт фасада (deprecated) import Helper from '../utils/helpers/data-helper'; // Использование (все методы доступны через фасад) const seconds = Helper.parseTimeToSeconds("1:23.45"); const levelInfo = Helper.getNormativeLevelInfo({ ... });
