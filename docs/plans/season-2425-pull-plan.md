## 1. Как тянем — пакет «⏬ Затянуть все незатянутые» в ProdAdmin

Механизм готовый ([bulk-pull-plan.md](bulk-pull-plan.md)): на каждую строку — то же превью, что у
одиночного «Затянуть» (PDF HE+EN → разбор → проба клубного зачёта → регламент → рекорды), затем
классификация. **Импортируются только отмеченные**, проблемные остаются сами:

| Класс превью | В импорт |
|---|---|
| 🟢 беспроблемная | да |
| 🟠 без регламента (ссылки `תקנון` нет / PDF не разобрался) | по умолчанию да — **решение Р-1** |
| 🟡 бьёт рекорд / уже есть в БД / больше одного дня / шкала очков не совпала / предупреждения парсера | нет — остаётся |
| 🔴 забор или разбор упал | нет — остаётся |
| ⚪ «нечего тянуть» | нет; ставится `EmptySourceAt` |

Пакет никогда не ставит «перезаписать» и «удалить лишние»; чемпионаты (по имени или по регламенту)
исключены по умолчанию; cap пачки — 30 строк; строки идут последовательно (loglig не долбим).
Импорт — через обычную очередь, видно в /Admin/ImportHistory.

⚠ **Пакет вживую ещё не нажимали ни разу** (код и тесты с 23.08.2026). Отсюда шаг 0.
