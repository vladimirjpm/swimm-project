## 1. Решения Влада (12.11.2026) — не переобсуждать

Хендофф оставил открытыми диалог, число результатов и фото (§2.7). Влад принял предложенные
умолчания одним ответом («Да, все принимаю»):

| # | Решение |
|---|---|
| Р1 | **Кнопка `Poster` — в шапке карточки соревнования**, только когда выбран один пловец. В режиме All кнопки нет. В панели результата `Poster` не ставится: плакат — про все заплывы |
| Р2 | **Заплывы отмечаются галочками** в диалоге, по умолчанию отмечены все. Строки ужимаются, пока помещаются: до 8 на A, до 9 на B, до 10 на C. Заплывов больше предела — лишние по умолчанию сняты: сперва без медали и без метки, потом поздние |
| Р3 | **DNS / DQ / DNF на плакат не идут** и в списке галочек не показываются. Предварительные заплывы идут: место как в протоколе, без медали |
| Р4 | **Фото пловца — как на обложке**: необязательное, файл с устройства, на сервер не уходит, по умолчанию без него. Без фото на A список результатов занимает всю ширину, на C результаты занимают освободившееся место; рамка-заглушка в файл не попадает |
| Р5 | **Файл — PNG 1414×2000 в браузере**; переключатель `Print quality` — 2828×4000 |
| Р6 | **Строка под названием**: «חורף» / «קיץ» по правилу значка сезона плитки + год соревнования; «גילאי 8-11» из возрастной группы категории, нет группы — только сезон и год. Строка на иврите, как в макете |
| Р7 | **Значок соревнования**: значок серии; без значка у чемпионата — кубок; иначе блок значка УБИРАЕТСЯ, результаты поднимаются (на обложке место остаётся пустым — на плакате значок крупный, была бы дыра) |
| Р8 | **Время без ведущих нулей** и без буквы `s`: `49.61`, `1:37.05` |
| Р9 | **Имя — «фамилия имя»**, как на сайте (в макете «имя фамилия») |
| Р10 | **Почти пустую плитку соревнования не показывать** (13.11.2026, по стенду): «не надо, если там почти пусто и нет хотя бы M или K 8-11». Плитка есть, только если есть буква категории или возрастная группа — `hasTileContent`. Действует на шапку карточки, обложку и плакат; страница результатов не тронута |

**Истолковано исполнителем** (Влад отдельно не подтверждал):

- Счёт медалей и `6 swims` на плакате B считаются по ВСЕМ заплывам пловца с результатом, а не
  только по отмеченным галочками: это итог соревнования. Снял галочку — строка ушла, счёт остался.
- Строка `1 age record` под `6 swims` — число рекордов; виды разные — `2 records`; рекордов
  нет — строки нет.
- Порядок строк — по дням соревнования; внутри дня — как в карточке.
- Без фото на A: две колонки строк берутся, только если так заметно крупнее (правило
  `fitGrid`); при 6 заплывах остаётся одна колонка по центру панели.
- На C больше пяти результатов с фото — две ленты поровну (6 → 3 + 3), фото становится ниже
  (530 вместо 730). Без фото — сетка на весь низ, ячейки до ×1,8.
- На B без значка таблица может увеличиться до ×1,25 (место блока значка достаётся ей).
- Значок сезона на C — рисунок (снежинка из макета; солнце нарисовано в той же линии, в макете
  летнего варианта нет): эмодзи плитки у каждой системы своё.
- Панель результатов на A стоит как в макете с правками Влада: `left 713, width 685` — правый
  край заходит за поле 86px (до 1398).
- Плитка в шапке B — размер `cover-lg` (110×134) вместо 108×130 макета: новый модификатор ради
  двух пикселей не заводился.

## 2. Как сделано

Требование Влада (12.11.2026, постоянное): «чистый код, разделённый, чтобы не было больших
кусков и было легко ориентироваться и менять». Плакат — в своей папке; то, что нужно и обложке,
и плакату, — в общей `print/`, без копий.

```
my-media-project/
  swim-marks.ts            медаль, метки рекорд/SB/PB, подпись стиля — общие для списка, обложки, плаката
  components/swim-list.tsx только кнопки и хосты диалогов (CoverButton, PosterButton)
  print/                   ОБЩЕЕ обложки и плаката
    print-data.ts          значок или кубок, одна метка (рекорд > SB > PB), дистанция — чистые функции
    print-data.test.mjs
    print-theme.ts         цвета макета, токены готовых компонентов, корень картинки
    print-fonts.ts         шрифты: регистрация и @font-face с data-URL (Heebo 700/800/900, Montserrat, Open Sans)
    print-export.ts        DOM → PNG заданного размера и скачивание, без React
    print-photo.ts         фото с устройства → data-URL
    print.css              обводка времени, подгонка готовых компонентов (класс .prn)
    parts/                 background, emblem-mark (значок, кубок), fit-text, name-row, photo
                           (слот фото и рамка-подсказка), place (кружок, медаль с лентой),
                           result-text (время, метка), style-plate
    dialog/                layout-picker, print-preview, photo-controls (чекбокс, выбор фото),
                           use-print-download
  cover/                   обложка YouTube: своё — данные, раскладки, угол со значком, верх с
                           плашкой-календарём, чекбоксы B и C
  poster/
    poster-entry.tsx       кнопка Poster + ленивый хост диалога
    poster-dialog.tsx      диалог: состояние и сборка частей
    poster-data.ts         ЧТО печатать — чистые функции (время, метка, строка сезона, счёт медалей)
    poster-selection.ts    какие заплывы отмечены: предел раскладки, выбор по умолчанию, галочка
    poster-fit.ts          подгонка сетки строк под их число (колонки и масштаб)
    *.test.mjs             юнит-тесты трёх модулей выше (npm --prefix client test)
    poster-source.ts       мост MySwimDto → данные плаката (общие isMedal / swimMarks)
    poster.tsx             плакат выбранной раскладки, узел для экспорта
    poster-theme.ts        размер 1414×2000, цвета плаката, размер файла
    layouts/               poster-a.tsx, poster-b.tsx, poster-c.tsx — по раскладке на файл
    parts/                 poster-text (имя, название, строка сезона, год), poster-marks (метка,
                           место), poster-emblem, result-parts (плита и время в масштабе строки),
                           results-grid, result-row (A), result-cell (C), table-row (B),
                           medal-tally (B), season-icon (C)
    dialog/                swim-picker (галочки заплывов), use-poster-selection
```

- **Раскладки** — фиксированный размер 1414×2000, размеры и кегли из inline-стилей макетов,
  именованными константами в начале файла раскладки или части.
- **Подгонка под число заплывов** (`poster-fit.ts`, `fitGrid`): ячейка результата описана в
  масштабе 1 (размеры макета), сетка подбирает число колонок и общий масштаб так, чтобы всё
  поместилось в отведённую область; строка рисуется в этом масштабе (`scaled`). В макетах 5–6
  результатов — при них масштаб 1.
- **Готовые компоненты:** `CompetitionTile` (новые размеры `poster` 132×160 и `poster-lg`
  150×182), `UI_SwimmStyleIcon`, `UI_ClubLogo`, `UI_MedalIcon` (новая ступень `medal-96` —
  место в таблице B; под масштаб строки ужимается transform-ом).
- **Данные** — `posterSourceForSwims` теми же хелперами, что строка списка и обложка: медаль —
  `isMedal` (`HelperResults.isMedalPlace`, место ≠ медаль), метка — `swimMarks` → `topMark`.
  **Р76:** у строки с `suspect_reason` `swimMarks` меток не даёт — на плакате их нет; время и
  место — как в протоколе.
- **Обложка после выноса общего** работает как раньше — повторный экспорт трёх раскладок, §4.
  Изменилось в её коде: имена семейств шрифтов `Print …` вместо `Cover …`, класс корня `.prn`
  вместо `.ytc`, атрибут пропуска `data-print-skip`.

## 2-бис. Плитки нет — что на её месте (Р10)

Одна точка — `print/parts/print-tile.tsx` (`PrintTile`): рисует `CompetitionTile` только при
`hasTileContent`. Раскладки:

| Где | Без плитки |
|---|---|
| Шапка карточки `/my-media` | текст (имя, название, даты) начинается от левого края |
| Обложка A и B | левая колонка верха пустая, название и плашка-календарь остаются по центру |
| Обложка C | в тёмной колонке значок встаёт по центру высоты под датой и годом (раньше — между годом и плиткой) |
| Плакат A | правый верхний угол свободен, год остаётся по центру, логотип клуба слева |
| Плакат B | в шапке логотип слева и строка сезона по центру, справа пусто |
| Плакат C | название со строкой сезона занимает место плитки в полосе (при значке справа блок названия смещён влево) |

**Почему у Эйлата плитка пустая** (проверено по локальной базе 13.11.2026): это данные, не
ошибка передачи. У дней 1874 и 1875 в `CategoryCompetitions` одна категория — кастомная
`results-8-99` («Age 8-99», Id 8). `MySwimDto.category` несёт только КАНОНИЧЕСКИЙ таб
(`CompetitionCategories.Canonical`: masters, kids, youth, juniors, adults), у кастомной категории
его нет — приходит `null`, буквы и возрастной ленты нет. Для сравнения: у дня 1870 категории
`results-main` и `results-junior-results` — канонический таб есть. Показывать ли для кастомной
категории её возраст («8-99») — отдельное решение, не делалось.

## 4. Что проверено и что нет

Проверено 12.11.2026 локально (API на 5079 с локальной базой, клиент на 5181, встроенный
браузер на Chromium), аккаунт по умолчанию, 6 заплывов Эйлата 05–06.11.2026 одной пловчихи.
Скачанные PNG открыты и просмотрены:

- A, B, C без фото и без значка: 1414×2000, шрифты макета, иврит справа налево, логотип клуба,
  иконки стилей, медали по правилу (2 золота, 3 серебра, 1 бронза), `PB`, `Relay` на B, `4X50`;
- A, B, C со значком соревнования и A, C с фото (файл подан в поле выбора скриптом);
- A, B, C с кубком (чемпионат без значка);
- 8, 9 и 10 строк (A, B, C) — заплывы были удвоены временной правкой, строки без медали дают
  место числом; предел раскладки гасит лишние галочки;
- 2 заплыва (A с фото, B); `Print quality` — файл 2828×4000, 7,0 МБ;
- обложка YouTube после выноса общих частей: A, B, C и B, C с фото — как до правки.

Вес файла 1414×2000 — 2,0–3,0 МБ.

**Не проверено:**

- значок через настоящую серию (`MySwimDto.emblem_url`): пробная серия в локальной админке не
  заводилась — значок подставлялся файлом макета со своего источника временной правкой. Путь
  адреса тот же, что у обложки, а там он проверен с настоящей серией;
- Safari и Firefox (экспорт идёт через SVG `foreignObject`; проверен только Chromium);
- настоящий выбор файла окном системы и настоящий клик мышью по `Download` — панель браузера
  была скрыта, действия шли из скрипта, файл принимался локальным приёмником. В скрытой
  вкладке экспорт ждёт `requestAnimationFrame` — для проверки он был подменён таймером;
- вид диалога глазами (снимок экрана скрытой панели не делается): состав и работа контролов
  проверены по DOM;
- метки рекорда и SB, строка `Under review`, предварительный заплыв, плитка с буквой категории
  и возрастной лентой, строка «גילאי …», длинные имя и название — таких данных у пловчихи
  локально нет (правила покрыты юнит-тестами, код меток общий с обложкой);
