## 5. Грабли

**Прод (14–17.10):**
- **`prod-sql.mjs` звать голой командой из корня репо** — `node server/db/prod-sql.mjs …`. С `cd … &&`
  или `| grep` команда не совпадает с правилом в `.claude/settings.local.json`, и её режет классификатор.
- **У `swimm_rw` нет `setval`.** Вставка с явными Id → счётчик двигать циклом `nextval` до `max(Id)`
  (так перенесена группа 17). Иначе следующая запись сайта упадёт на занятом Id.
- **Пловцы групп (`PrivateHubGroupId`) и `HubGroups` синхронизацией не ездят** (`dump-seed.sh` их
  вырезает) — у группы на проде своя жизнь; правки тренировок в локальной на сайт не попадут.
- **Секреты не читать и не печатать** — даже хвост ключа. Пароли вводит Влад сам (`Read-Host
  -AsSecureString`, вставка ПРАВОЙ кнопкой: Ctrl+V в PowerShell 5.1 вставляет один символ).
- **Git Bash переписывает пути** в аргументах `az`/`docker` (`/home/...` → `C:/Program Files/Git/...`) —
  `MSYS_NO_PATHCONV=1`.
- **PowerShell 5.1:** переменные регистронезависимы (`$Src` = `$src`); запятая связывает сильнее минуса.
- **API Влада на :5078 запущен** — `dotnet build` упадёт на блокировке; не убивать. Проверка сборки —
  `-p:OutDir=<scratchpad>/buildcheck/`.
- **Не путать сервисы с рекламой:** «UptimeRobot» в поиске может оказаться Datadog (платный триал).
- **Azure показывает расходы с задержкой** в сутки — $0 в бюджете первые дни норма.

**Данные (10.10, по-прежнему в силе):**
- **Склейка пары HE+EN сопоставляет СОБЫТИЯ ПО НОМЕРУ** — потерянное событие роняет пару, импорт молча
  идёт одним ивритом. Проверка: `--repull <id> --dry-run` печатает «Пара HE+EN не склеилась (…)».
- **`--repull` с мастерскими эстафетами заводит теней из ног** и откатывает склейки, если loglig пишет
  имя иначе — сверять пловцов до/после, теней — `--merge-swimmers`; многодневки — сначала `--split-days`.
- **Программа loglig без `dateFilter=הכל` — только сегодняшний день.** Английская карточка loglig —
  только с двумя куками (`_culture=en-US; DetailsPageVisited=visited`).
- **CLI-записи и прямой SQL идут мимо кэша запущенного API** — сбросить кэш на `/Admin/Cache` или
  перезапустить. На проде `prod-sql.mjs` сбрасывает сам, если файл шлёт `pg_notify('swimm_cache', …)`.
- **InMemory-тесты не видят check-ограничений и длины колонок Postgres** — новые пути записи → `*PgTests`.
- **Аккаунт по умолчанию на стенде — живой аккаунт Влада**: только читать. Персонажи —
  `/api/dev/persona?as=utest-…`, вернуть — `?as=default`.
- **Python в Git Bash** — полным путём `C:/Users/Vlad/AppData/Local/Python/pythoncore-3.14-64/python.exe`,
  с `-I`; кириллица — `sys.stdout.reconfigure(encoding='utf-8')`.
