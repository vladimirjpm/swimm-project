## 5. Грабли (уже в памяти, повторяю, чтобы не наступить)

**Новые 10.10 (вечер):**
- **Склейка пары HE+EN сопоставляет СОБЫТИЯ ПО НОМЕРУ**, а дату, пол и категорию события берёт из
  EN-разбора. Любое событие, которое одна ветка теряет или дробит иначе, роняет пару целиком —
  импорт молча идёт одним ивритом. Проверять: `--repull <id> --dry-run` печатает «Пара HE+EN не
  склеилась (…)». Перед перезаливом парой — сравнить разбор пары с разбором одного иврита по полям
  ключа (скрипт в scratchpad сессии; приём — И-52).
- **`--repull` с мастерскими эстафетами заводит теней из ног**, если loglig пишет имя иначе, чем
  карточка («בודנר» ↔ «פישל-בודנר»). После перезалива: снимок ног «до/после» по (эстафета, нога),
  новых пловцов без личных строк — `--merge-swimmers` обратно.
- **Этапы ног пишет не только доклейка** — сборка мастерских эстафет при импорте тоже; поэтому сторож
  Р82 стоит и в импорте (`ClearImplausibleLegsAsync`).
- **loglig бывает неверен в одном языке**: английская карточка с чужим именем при верной ивритской;
  список федерации (discovery `DateStart`) ошибается на день — верить сетке loglig и протоколу.
- **Федерация печатает некоторых пловцов с переставленными половинами имени** (близнецы יבסייב,
  #59052) — HE-поля таких карточек не «чинить» перестановкой: Р83 узнаёт только при том же клубе.
- **Мутации через `sed` в Git Bash молча не срабатывают** (CRLF, спецсимволы) — заменять Python-скриптом,
  который сам учитывает CRLF и ПЕЧАТАЕТ «mutated»; без этой строки мутации не было.
- **Окно Share в My media открывается только из раздела Unlinked.** Живая проверка — персонаж
  `utest-media-author` + пловчиха #59912 в избранном (после — убрать).

**Новые 10.10 (утро):**
- **Программа loglig без `dateFilter=הכל` — только сегодняшний день**, если он есть в программе.
- **loglig печатает сломанные строки промежуточных** (`-1.-29:00`, нарастающие переставлены) — сумма
  этапов всё равно равна итогу, сторожа описаны в `relays.md`.
- **Английская карточка loglig** — только с ДВУМЯ куками (`_culture=en-US; DetailsPageVisited=visited`),
