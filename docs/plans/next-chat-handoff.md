## 4. Как работать с продом (В17)

- **Главная база — прод.** Локальная — копия (`/db-sync-from-prod`). Агент сам в прод не пишет без просьбы.
- **SQL на проде:** `node server/db/prod-sql.mjs read -c "SELECT …"` (или `read <file.sql>`) — свободно, только
  чтение. Запись — только по просьбе Влада: файл `BEGIN … COMMIT` в `server/db/private/` → `local` → `apply`.
- **Миграция на прод (агент, после мержа, ДО деплоя кода):**
  `powershell -File server/db/prodadmin-firewall.ps1` (IP Влада меняется), затем из master
  `dotnet run --project server/Swimm.API --launch-profile ProdAdmin --artifacts-path <scratchpad>/prodadmin-migrate -- --migrate`.
  `--artifacts-path` — чтобы не упереться в `bin/Debug`, если ProdAdmin Влада запущен. Проверка —
  `__EFMigrationsHistory` через `prod-sql.mjs read`. Перед этим полезно прогнать выборку переноса данных из
  миграции на проде только чтением (так сделано для CF5).

## 5. Грабли этой сессии

- **ProdAdmin Влада держит `bin/Debug` и порт 5078.** Не трогать без спроса. Сборки агента — `-c Release`
  или `-p:OutDir=<scratchpad>/…`; миграции EF — `--configuration Release`. «Почему не запускается ProdAdmin»
  — почти всегда живой старый процесс (`Stop-Process` по PID, порт 5078). **«Останови всё» от Влада включает
  его ProdAdmin.**
- **После мержа — перезапуск ProdAdmin.** Он работает со старым кодом (без новых полей API), а клиент на
  :5173 уже новый — отсюда «не вижу на localhost» (так было со значком 18.11).
- **Тесты из временной папки сборки:** 6 тестов, читающих файлы репозитория (`HostingModeTests`,
  `DataVersionPgTests`…), падают — это не регресс; гонять из обычной сборки (`dotnet test -c Release`).
- **Стражи, которые ловят новые таблицы:** `TrainingResultsPrivacyTests` (кто читает `TrainingSessions`) и
  `SwimmerDedupServiceTests.OrphanQuery_CoversEveryTableReferencingSwimmer` (новая ссылка на `Swimmers`).
- **Стенд для проверки в браузере:** `stack-5181-api5079-personas` (Release, `--no-build` — сперва
  `dotnet build -c Release`); персонажи — `/api/dev/persona?as=utest-coach`, вернуть — `?as=default`.
  Аккаунт по умолчанию — живой аккаунт Влада: только смотреть. Тестовые данные (расписание `utest-open`,
  планы, ответы) после проверки возвращать.
- **Правки скриптами на Windows:** sed понимает обратную кавычку как «начало буфера», а heredoc с кириллицей
  и `'''` ломается — длинные правки писать Python-скриптом в файл (`python -I script.py`), с проверкой «ровно
  одно вхождение».
- **По-прежнему в силе:** `prod-sql.mjs` звать голой командой из корня репо; секреты не читать и не печатать;
  не `git add -A` (в рабочей копии файлы Влада); Python в Git Bash — полным путём, с `-I`.
