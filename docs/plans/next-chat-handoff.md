## 4. Грабли (уже в памяти, повторяю, чтобы не наступить)

- **Несколько сессий в одной рабочей копии.** Другая сессия может застейджить свои файлы между твоими
  командами — перед коммитом смотри `git diff --cached`; коммить явными путями
  (`git add -- <пути>` / `git commit -- <пути>`) или через временный индекс (`GIT_INDEX_FILE`),
  `git add -A` нельзя.
- **Файл со своими И чужими правками** (обычно `docs/data-integrity.md`, `docs/ROADMAP.md`) —
  индексную версию собирать как «HEAD + только свои куски» (`git hash-object -w --stdin` +
  `git update-index --cacheinfo`). ⚠ `hash-object --stdin` НЕ нормализует концы строк: блоб должен
  быть с LF (поймано 07.10, исправлено в `ac8610bb`). Проще — такие файлы не трогать.
- **`sed -i` в Git Bash может переписать концы строк всего файла** (дифф на каждую строку). Правки
  кода и доков — через Edit; если sed всё же нужен — копия файла заранее и `git diff --stat` после.
- **`--repull` откатывает склейки пловцов**, если протокол пишет имя иначе и правило Р79 не ловит (другой
  клуб, двое кандидатов) — сверять число пловцов до/после; склеить обратно `--merge-swimmers`.
  У схлопнутых многодневок `--repull` теперь сам отказывается — сначала `--split-days`.
- **API Влада на :5078 не трогать.** Стенд для проверки — `stack-5183-api5082-personas`
  (API :5082 из Debug `--no-build` + Vite :5183; админка на `http://localhost:5082/Admin/*` открывается
  без логина — DevAdminBypass). Правил Razor/C# — пересобрать (`dotnet build server/Swimm.API`) и
  перезапустить стенд. После проверки — `preview_stop`, порт свободен.
- **Аккаунт по умолчанию на стенде — живой аккаунт Влада**: на нём только читать (никаких лайков,
  удалений, отправки заявок). Тестовые персонажи — `/api/dev/persona?as=utest-…`, вернуть —
  `?as=default`.
- **Проверять в панели браузера приложения** (`mcp__Claude_Browser__*`). Первая навигация после старта
  стенда часто пустая — подождать ~10 с. Скриншот может не отрисоваться, если окно за другими, —
  проверять текстом (`get_page_text`, `javascript_tool`). Запросы — `read_network_requests` в
  НОВОЙ вкладке на сценарий (журнал копится по вкладке); Resource Timing не годится — буфер забивают
  модули Vite. PDF с isr.org.il панель не открывает — читать текстом (`pypdf`, `extraction_mode='layout'`).
- **Приёмы сверки «до/после»** (рефакторинг показал, что работают): эталон снимать ДО правки и
  дважды; экран — SHA-256 `innerText`/`outerHTML` после каждого шага сценария; страницы админки —
  `server/tools/refactor/admin_page_snapshot.py`; тесты — мутациями (сломать правило в коде, тест
  обязан упасть). Инструменты — `server/tools/refactor/README.md`.
- **InMemory-тесты не видят check-ограничений Postgres**, и навигация `r.Swimmer.*` в проекции требует
  карточек пловцов в тестовой базе (иначе строки пропадают на join).
