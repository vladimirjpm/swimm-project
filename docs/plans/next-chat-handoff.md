## 4. Грабли этой сессии (уже в памяти, повторяю, чтобы не наступить)

- **Debug-сборку держит API Влада на :5078** — процесс не трогать. Сборка, тесты, миграции —
  `-c Release` / `--configuration Release`; стенд — **`stack-5181-api5079-personas`** (API :5079 из
  Release `--no-build` + Vite :5181). Перед стартом стенда пересобрать Release, иначе API старый.
- **Проверять в панели браузера приложения** (`mcp__Claude_Browser__*`, `resize_window` mobile/dark,
  `javascript_tool`). gstack `/browse` при сбое старта плодил десятки окон `bun.exe` у Влада и
  сбрасывал персонажа на настоящий аккаунт Влада. Перед любой записью через UI — `GET /auth/me`.
- **InMemory-тесты не видят check-ограничений Postgres** — перед «миграции не нужно» смотреть
  `\d "<таблица>"`; новый путь записи в таблицу с CK/FK — тест `*PgTests` (образец
  `TrainingMediaTagPgTests`).
- **Первая навигация после старта стенда** часто «denied or failed» — повторить; холодный Vite
  грузит страницу до ~10 с — ждать элемент в цикле, а не `sleep 3`.
- **Рабочая копия общая с другой сессией**: в ней сейчас чужие незакоммиченные `CLAUDE.md`,
  `docs/data-integrity.md`, `SwimmerDedupService.cs` + тест, `docs/masters-records-rules.md` и файлы
  Влада `!design_handoff/…` — коммитить только свои пути, `git add -A` нельзя.
