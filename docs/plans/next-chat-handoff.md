## 4. Как работать с продом (В17)

- **Главная база — прод.** Локальная — копия (`/db-sync-from-prod`). Агент сам в прод не пишет без просьбы.
- **SQL на проде:** `node server/db/prod-sql.mjs read -c "SELECT …"` (или `read <file.sql>`) — свободно, только
  чтение. Запись — только по просьбе Влада: файл `BEGIN … COMMIT` в `server/db/private/` → `local` → `apply`.
- **Миграция на прод (агент, после мержа, ДО деплоя кода):**
  `powershell -File server/db/prodadmin-firewall.ps1` (IP Влада меняется), затем из master
  `dotnet run --project server/Swimm.API --launch-profile ProdAdmin --artifacts-path <scratchpad>/prodadmin-migrate -- --migrate`.
  `--artifacts-path` — чтобы не упереться в `bin/Debug`, если ProdAdmin Влада запущен. Проверка —
  `__EFMigrationsHistory` через `prod-sql.mjs read`.
- **Пароли прод-ролей Влад сменил 19.11** (они попали в переписку одного из чатов). Секреты не читать и не
  печатать, `appsettings.*.Local.json` не grep'ать — их берут скрипты.

Новое за 19.11:

- **ProdAdmin на старом коде портит данные проверок.** 19.11 кнопка «Прогнать проверки» в ProdAdmin до #224
  заново открыла 12 закрытых находок очков. После каждого мержа — перезапуск ProdAdmin из master (делает

- **Склейка клубов через API ProdAdmin идёт дольше 45 с** — `javascript_tool` встроенного браузера не
  дожидается ответа. Повторно не слать: результат смотреть в базе (`MergedIntoId`, число результатов у дубля).
  Заголовок антифорджери — `X-XSRF-TOKEN: _csrfToken` (переменная есть на страницах `/Admin/*`, на `/` её нет).
- **Команды внутри прод-контейнера (`az rest … scm …/api/command`) агенту запрещены** правами сессии. Нужна
  проба с прода — команду запускает Влад в консоли App Service.
- **DNS на машине Влада иногда не находит** `swimhub-pg.postgres.database.azure.com` / `loglig.com` —
  разовый сбой, повтор через минуту проходит (18.11 из-за этого упал фоновый забор 4 стартов).
- **Незакоммиченная правка отслеживаемого файла в основной папке** мешает соседям (переключают ветки) и
  теряется из виду: документы писать в своём worktree и вливать PR-ом, когда Влад попросит коммит.
- **Сообщение Влада «абракадаброй» на иврите** — русская фраза в ивритской раскладке; раскладывать по клавишам.

По-прежнему в силе:

- **ProdAdmin Влада держит `bin/Debug` и порт 5078.** Не трогать без спроса. Сборки агента — `-c Release`
  или отдельный worktree. «Почему не запускается ProdAdmin» — почти всегда живой старый процесс. **«Останови
  всё» от Влада включает его ProdAdmin.** `preview_start` ProdAdmin агенту запрещён — запускает Влад.
- **`run-prodadmin.ps1` не стартует**, если основной чекаут на другой ветке с незакоммиченными правками или
  `master` занят другим worktree (`git worktree list`).
- **Консоль против прода без ProdAdmin-процесса** — сборка в `C:\_Proj\swimm-dashcheck` и
  `dotnet <dll> --environment ProdAdmin --contentRoot C:/_Proj/swimm-project/server/Swimm.API <команда>`
  (секреты есть только в основном чекауте). Подробно — `docs/dashboard-check.md` §0.
- **Тесты из временной папки сборки** (`--artifacts-path`): тесты, читающие файлы репозитория, падают — не
  регресс; гонять обычной сборкой. Полный набор на 19.11 — 4391, ~2,5 мин.
- **Автомерж запрещён:** мержить руками после зелёного CI (самая долгая проверка — «Сервер», ~4–5 мин).
  Ждать CI — `gh pr checks <N> --watch` в фоне, не опросом.
- **`server/db/prodadmin-firewall.ps1` агенту запрещён** — нужен, когда у Влада сменился IP (`prod-sql.mjs
  read` не подключается): попросить Влада.
