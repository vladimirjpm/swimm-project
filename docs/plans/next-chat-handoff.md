## 4. Грабли (уже в памяти, повторяю, чтобы не наступить)

- **Несколько сессий в одной рабочей копии.** Другая сессия может застейджить свои файлы между твоими
  командами — перед коммитом смотри `git diff --cached`; коммить явными путями
  (`git commit -- <пути>`) или через временный индекс (`GIT_INDEX_FILE`), `git add -A` нельзя.
- **Файл со своими И чужими правками** (обычно `docs/data-integrity.md`) — индексную версию собирать
  как «HEAD + только свои куски» (`git hash-object -w --stdin` + `git update-index --cacheinfo`).
  ⚠ `hash-object --stdin` НЕ нормализует концы строк: блоб должен быть с LF, иначе CRLF уедет в
  репозиторий и git перестанет нормализовать файл (поймано 07.10, исправлено в `ac8610bb`).
- **`--repull` откатывает склейки пловцов**, если протокол пишет имя иначе и правило Р79 не ловит (другой
  клуб, двое кандидатов) — сверять число пловцов до/после; склеить обратно `--merge-swimmers`.
  У схлопнутых многодневок `--repull` теперь сам отказывается — сначала `--split-days`.
- **Debug-сборку может держать API Влада на :5078** — его процесс не трогать; стенд для проверки —
  `stack-5183-api5082-personas` (API :5082 из Debug `--no-build` + Vite :5183) или `stack-5181-api5079-personas`
  (Release — перед стартом пересобрать Release). После проверки — `preview_stop` и погасить `dotnet` на порту.
- **Проверять в панели браузера приложения** (`mcp__Claude_Browser__*`). Первая навигация после старта
  стенда часто пустая или «Loading…» — подождать ~10 с и повторить. PDF с isr.org.il панель не
  открывает (отдаётся скачиванием) — читать текстом с раскладкой (`pypdf`, `extraction_mode='layout'`).
- **InMemory-тесты не видят check-ограничений Postgres**, и навигация `r.Swimmer.*` в проекции требует
  карточек пловцов в тестовой базе (иначе строки пропадают на join).
- В Bash-оболочке `python` может не находиться (алиас Microsoft Store) — правки файлов делать через Edit.
