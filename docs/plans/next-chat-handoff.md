## 5. Грабли (уже в памяти, повторяю, чтобы не наступить)

**Новые 10.10:**
- **Программа loglig без `dateFilter=הכל` — только сегодняшний день**, если он есть в программе.
  Адрес с фильтром отдаёт частичную вьюху без шапки — `seasonId` и регламент берутся с полной
  страницы (`LogligClient`).
- **loglig печатает сломанные строки промежуточных** (отрицательный отрезок `-1.-29:00`, нарастающие
  переставлены). Сумма разностей нарастающих всё равно равна итогу — проверка «сумма этапов = итог»
  тут бесполезна, сторожа описаны в `relays.md`.
- **Английская карточка loglig** — только с ДВУМЯ куками (`_culture=en-US; DetailsPageVisited=visited`),
  и не через общий клиент «loglig» (контейнер кук один на всё). У игрока без латиницы заголовок на иврите.
- **Infrastructure не ссылается на Parsing.** Общая логика имён/времени — в `Swimm.Application/Mapping`.
- **Docker из Git Bash**: `/tmp` в аргументах переписывается в путь Windows — `MSYS_NO_PATHCONV=1`, а
  для `docker cp` наружу путь писать по-виндовому (`C:/_Proj/...`).
- **Python-heredoc** (`<<'EOF'`) с `\\n`/`\\t` внутри тройных кавычек кладёт в C# настоящие перевод
  строки и табуляцию — править такие места через Edit.
- **CLI-записи идут мимо кэша запущенного API** — после `--attach-splits`, `--fix-en-names`, прямого SQL
  сбросить кэш на `/Admin/Cache` (или перезапустить API) перед проверкой витрины.

**Прежние:**
- **Несколько сессий в одной рабочей копии.** Перед коммитом — `git diff --cached`; коммить явными
  путями (`git add -- <пути>` / `git commit -- <пути>`), `git add -A` без путей нельзя.
- **Файл со своими И чужими правками** (обычно `docs/data-integrity.md`, `docs/ROADMAP.md`) — индексную
  версию собирать как «HEAD + только свои куски» (`git hash-object -w` + `git update-index --cacheinfo`).
  ⚠ Блоб должен быть с LF. Так сделано 10.10 для И-50 — работает.
- **`sed -i` в Git Bash может переписать концы строк всего файла.** Правки — через Edit; иначе копия
  файла заранее и `git diff --stat` после.
- **`--repull` откатывает склейки пловцов**, если протокол пишет имя иначе — сверять число пловцов
  до/после; у схлопнутых многодневок он сам отказывается — сначала `--split-days`.
- **API Влада на :5078 не трогать.** Стенд — `stack-5183-api5082-personas` (API :5082 из Debug
  `--no-build` + Vite :5183; админка на `http://localhost:5082/Admin/*` без логина). Правил C# —
  `dotnet build server/Swimm.API` и перезапуск стенда; после — `preview_stop`.
- **Аккаунт по умолчанию на стенде — живой аккаунт Влада**: только читать. Персонажи —
  `/api/dev/persona?as=utest-…`, вернуть — `?as=default`.
- **Проверять в панели браузера приложения.** Первая навигация после старта часто пустая — ~10 с.
  Скриншоты и клики не проходят, если окно за другими, — проверять текстом (`get_page_text`,
  `javascript_tool`). PDF с isr.org.il — читать текстом (`pypdf`, `extraction_mode='layout'`).
- **Приёмы сверки «до/после»**: эталон ДО правки; снимок значений в TSV и разбор «дописано / перезаписано /
  обнулено» по видам; тесты — мутациями. Инструменты — `server/tools/refactor/README.md`.
- **InMemory-тесты не видят check-ограничений Postgres**; тест, который сеет и проверяет одним
  контекстом, видит закэшированные трекером старые значения — сервису давать свежий контекст.
