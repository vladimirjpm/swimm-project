# Черновик: «Нужна ли вам группа?» — памятка перед созданием группы

Статус: **черновик, копим материал** (заведён 29.09.2026 по просьбе Влада). Из него потом
соберём документ для пользователя, который он читает ПЕРЕД созданием группы. Язык будущей
страницы — английский (правило «видимый UI только на английском»); здесь — русский черновик.

## 1. Главный вопрос: группа или избранное?

**Если вы следите за пловцами один — группа не нужна, хватит избранного.** Избранное — личный
список, его видите только вы; «семью» (своих детей) отмечает золотое сердечко, отдельная
страница — `/my-favorites`.

**Группа нужна, когда людей несколько и у них есть общее:**
- общий список пловцов, который видят все участники, а не каждый у себя;
- тренировки, расписание, «иду / не приду», дорожки;
- общие фото и видео, публикации участников;
- участники и заявки на вступление.

Антипример (разобран с Владом 29.09.2026): «мама создаёт группу „Мои дети и их друзья“» — ей
группа не нужна, это избранное.

## 2. Что значит «Following» в группе

Состав группы называется **Following** — «группа следит за этими пловцами». Группа не
заявляет, что они «плавают у нас»: добавить в группу можно любого пловца из протоколов
федерации, и название не должно ничего утверждать о чужих людях (решение Р65,
`docs/data-integrity.md`). У клуба состав называется Swimmers — он из данных федерации.

В Following бывают и пловцы из протоколов федерации, и «локальные» — их заводит тренер, в
протоколах их нет, они только тренируются в группе (пример — Дельфин Нетания мастерс: 5 из
протоколов + 18 локальных).

## 3. Примеры, когда группа нужна

### Пример 1. Общие сборы детей из разных клубов

Родители из разных клубов, чьи дети вместе едут на сборы, заводят группу «Сборы Эйлат-2026».
Добавляют детей из протоколов федерации, делятся видео со сборов, смотрят результаты на
стартах. Группа за этими детьми **следит** — сказать «плавают у нас» нельзя: у каждого свой
клуб. Поэтому состав и называется Following.

Что здесь делает группу нужнее избранного: людей несколько (родители), список общий, медиа
общие.

## 3а. Люди без аккаунта и без loglig

Если кто-то тренируется с группой, но не хочет заводить аккаунт и его нет в протоколах
федерации, тренер добавляет его сам: «+ Add a swimmer who isn’t on loglig» в составе группы.
Такой пловец виден **только внутри группы** — у него нет публичной страницы и его не найти
поиском (Р71). Его можно ставить на дорожки и записывать ему времена тренировок. Перестал ходить —
Deactivate: он пропадает из состава и дорожек, времена сохраняются, Restore возвращает.
Удалить насовсем (вместе с временами) можно из списка Inactive.

## 4. Что ещё войдёт в памятку (не написано)

- Открытая группа или по заявкам (`JoinPolicy`), кто её видит.
- Что такое Trusted и почему «Everyone 🌐» есть только у доверенной группы (Р65).
- Лимит групп на человека (политика создания, `docs/admin-pages/`).
- Официальная группа клуба: как подать заявку.
