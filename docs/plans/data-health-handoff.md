## 5. Грабли

- **Сборка рабочей копии ≠ закоммиченное.** В копии чужие правки (07.10 — поле `Distances` без
  миграции роняло тесты кэша). Тесты и превью гнать на сборке индекса:
  `git checkout-index -a --prefix=<scratchpad>/staged/` → `dotnet test … --artifacts-path <scratchpad>/art-staged`.
  Превью из неё — временная конфигурация в `.claude/launch.json` с `--contentRoot
  server/Swimm.API` (потом `git checkout -- .claude/launch.json`).
- **Индекс общий с параллельной сессией**: между `git add` и `git commit` она может закоммитить
  своё. После коммита — `git show --stat` обоих. Смешанные файлы (`data-integrity.md`,
  `relays.md`) — HEAD + свой кусок через `git hash-object -w` + `git update-index --cacheinfo`.
- **CLI** — `dotnet <scratchpad>/art/bin/Swimm.API/debug/Swimm.API.dll …` из `server/Swimm.API`,
  `ASPNETCORE_ENVIRONMENT=Development`. Кириллица в выводе через bash — «?»: гнать через PowerShell
  с `[Console]::OutputEncoding = UTF8`.
- **`--split-days` / `--attach-splits` / `--merge-swimmers` — сначала без записи**, бэкап перед
  записью (`docker exec swimm-postgres pg_dump -U swimm -d swimm -Fc > …`).
- **PG-тесты пишут в ЖИВУЮ базу** — свои строки + удаление в `finally`, `[Collection(LiveDbCollection.Name)]`.
- **Диагностика без проекта** — file-based C# в scratchpad (`#:project …Swimm.Parsing.csproj`,
  для JSON `#:property JsonSerializerIsReflectionEnabledByDefault=true`).
- Карточка игрока loglig — только с кукой: `curl -sL -c ck -b ck "https://loglig.com:2053/Players/Details/{id}?seasonId=1715"`.
- Тесты-сканеры `DirectMemoryCache_…`, `TrainingResults_ReadOnly…` вне дерева падают — норма.
- Номер И/Р — сверять с рабочей копией `data-integrity.md`: другие сессии пишут туда же.
