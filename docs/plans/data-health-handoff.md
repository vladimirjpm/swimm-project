## 5. Грабли

- **Сборка рабочей копии ≠ закоммиченное.** В копии чужие правки. Тесты и превью гнать на сборке
  индекса: `git checkout-index -a --prefix=<scratchpad>/staged/` + скопировать свои файлы →
  `dotnet test … --artifacts-path <scratchpad>/art-staged`.
- **Превью из сборки индекса** — временная конфигурация в `.claude/launch.json`:
  `cmd /c "set ASPNETCORE_ENVIRONMENT=Development&& dotnet <art-staged>\bin\Swimm.API\debug\Swimm.API.dll
  --urls http://localhost:5079 --contentRoot C:\\_Proj\\swimm-project\\server\\Swimm.API"`.
  `--contentRoot` — ТОЛЬКО абсолютный (относительный считается от папки dll), в JSON — двойные
  `\\`. Потом `git checkout -- .claude/launch.json`. Preview-пользователь
  (`claude.preview@example.com`) не админ — `/Admin/*` отвечает AccessDenied; без ключа входит
  админ из `appsettings.Development.json` (живой аккаунт Влада) — только смотреть, не писать.
- **Панель пачки без записи:** подменить в странице `window.fetch` для `/api/admin/discovery/bulk-(pull|import)`
  (остальное — настоящим fetch) и вести фазы руками — так проверены все состояния 08.10.
- **Индекс общий с параллельной сессией**: между `git add` и `git commit` она может закоммитить
  своё. После коммита — `git log` / `git show --stat`. Смешанные файлы (`data-integrity.md`,
  `relays.md`) — HEAD + свой кусок через `git hash-object -w --path=…` + `git update-index --cacheinfo`.
- **CLI** — `dotnet <scratchpad>/art-staged/bin/Swimm.API/debug/Swimm.API.dll …` из `server/Swimm.API`,
  `ASPNETCORE_ENVIRONMENT=Development`, `Logging__LogLevel__Default=Warning`. Кириллица в выводе
  через bash — «?»: гнать через PowerShell с `[Console]::OutputEncoding = UTF8`.
- **Бэкап из bash:** `MSYS_NO_PATHCONV=1`, иначе Git Bash превращает `/tmp/…` в Windows-путь и
  `pg_dump -f` внутри контейнера падает. В PowerShell `$$` в SQL блокирует весь вызов.
- **`--split-days` / `--join-days` / `--attach-splits` / `--merge-swimmers` — сначала без записи**,
  бэкап перед записью, после — `--check-data`.
- **PG-тесты пишут в ЖИВУЮ базу** — свои строки + удаление в `finally`, `[Collection(LiveDbCollection.Name)]`.
- **Диагностика без проекта** — file-based C# в scratchpad (`#:project …Swimm.Parsing.csproj`,
  для JSON `#:property JsonSerializerIsReflectionEnabledByDefault=true`).
- Карточка игрока loglig — только с кукой: `curl -sL -c ck -b ck "https://loglig.com:2053/Players/Details/{id}?seasonId=1715"`.
- Тесты-сканеры `DirectMemoryCache_…`, `TrainingResults_ReadOnly…` вне дерева падают — норма.
- Номер И/Р — сверять с рабочей копией `data-integrity.md`: другие сессии пишут туда же.
- Номера событий идут не подряд (#44 занят другой сессией) — номер брать из вывода команды.
- **Консольный перезалив тоже может завести тень** (И-46): после любого `--repull` смотреть
  `swimmers.dedup-sure` в `--check-data`. Проверка «что изменилось» — восстановить бэкап во
  временную базу (`createdb swimm_bak_X` + `pg_restore`) и сравнить строки соревнования
  построчно; потом `dropdb`.
- **Английская карточка loglig:** открыть любую карточку, затем `/Common/SetCulture?lang=en` с
  `Referer` — без Referer 500. Имя одной строкой «Имя Фамилия», иногда наоборот; EN бывает чужим
  (близнецы). 4 потока по ~1,5 с — 5000 карточек за ~40 мин.
- **Двойной обратный слэш в heredoc/скриптах** через инструмент иногда схлопывается в один — в
  Python-строках путей писать прямой слэш, в регулярке разделитель пути ловить точкой
  (`Cli.(\w+)\.cs`), а не экранированным обратным слэшем.
