локально. На прод не выкачено; на витрине значок **не показывается** — это следующая задача.

(`!design_handoff/my-media-handoff-nov2026/HANDOFF.md`, задача 2) — на обложке нужен значок

## 1. Решения Влада (12.11.2026) — не переобсуждать

| # | Решение | Почему |
|---|---|---|
| З1 | Значок висит на **серии** (`CompetitionSeries`), не на соревновании | Он нужен ежегодным турнирам: новый выпуск узнаётся по `MatchPhrases` и получает значок сам |
| З2 | Значок **необязателен** | У большинства стартов эмблемы нет |
| З3 | Картинка хранится **в базе байтами** (`bytea`) | Отвергнуто: файл в репозитории (деплой на каждый значок, чужие логотипы в публичном репо); диск сервера (ProdAdmin работает на машине Влада, диск прода перезаписывается при деплое); Azure Blob (новая инфраструктура ради десятка картинок) |
| З4 | Загружает только Влад, через админку (на проде — профиль ProdAdmin) | Админки на проде нет (В17) |
| З5 | Оригинал не хранится; уменьшение до ~512 px — **в браузере** | Не тащить в сервер библиотеку обработки изображений; ожидаемый размер значка 30–100 КБ |
| З6 | Публичный адрес есть, в витрину пока не встраиваем | Показ — отдельная задача (шапка соревнования, календарь, обложки My media) |

## 2. Как устроено

**Таблица `SeriesEmblems`** (публичная, не `Sys_*`): `Data bytea`, `ContentType`
(`image/png` | `image/webp`), `Width`, `Height`, `Sha256` (64 hex), `UploadedAt`.
У серии — необязательная ссылка `CompetitionSeries.EmblemId` с `ON DELETE SET NULL`:
удаление значка серию не ломает. Миграция `AddSeriesEmblems`.

- **Отдельная таблица, а не колонка серии** — серию читают часто (Overview, привязка при
  импорте), и тянуть с ней десятки килобайт незачем. Страница правки читает сведения о значке
  проекцией, без байтов.
- **Строка значка неизменяема.** Замена — новая строка (новый `Id`, новый хэш), старая удаляется
  тем же сохранением. Поэтому адрес можно кэшировать навсегда.
- **Каскада от серии к значку нет** (ссылка смотрит в другую сторону) — значок удаляет
  репозиторий при удалении серии (`SeriesAdminRepository.RemoveEmblem`). Удаляешь серию сырым
  SQL — удали и её значок, иначе останется строка-сирота (безвредная, но лишняя).
- **CHECK-ограничения** в базе повторяют проверку кода (тип из двух, размер 1…307200 байт,
  сторона 1…1024, хэш — 64 hex): в таблицу пишет не только репозиторий (синхронизация, ручной
  SQL), а отдаётся она анонимам.

**Проверка файла** — `Swimm.Application/Validation/SeriesEmblemImage.cs`, вызывается в
репозитории (`SetEmblemAsync`), обойти её со страницы нельзя:

- тип — по **сигнатуре** файла, заголовку `Content-Type` и расширению не верим;
- только PNG и WebP (растр без исполняемого содержимого; SVG и HTML отвергаются);
- размеры читаются из заголовка файла (PNG — IHDR; WebP — VP8 / VP8L / VP8X);
- обрезанный файл — отказ (PNG без IEND, WebP с длиной не как в RIFF); анимированный WebP — отказ;
- лимиты: 300 КБ (`MaxBytes`), сторона до 1024 px (`MaxSide`; браузер уменьшает до 512 —
  `TargetSide`, запас оставлен на двойную плотность).

**Админка** — блок «Значок серии» на `/Admin/Series/Edit` ([admin-pages/series.md](../admin-pages/series.md)):
выбор файла → canvas уменьшает и кодирует в WebP (браузер без WebP-кодировщика отдаст PNG) →
предпросмотр на тёмном и светлом фоне с размером → обычная отправка формы (antiforgery, PRG).
Мутации в аудите: `series.emblem.set`, `series.emblem.delete`.

**Список серий** (`/Admin/Series`, доработка 12.11.2026): колонка «Значок» — миниатюра по
публичному адресу, клик открывает значок крупно в `<dialog>` поверх страницы (тёмный и светлый
фон; закрытие крестиком, кликом мимо, Esc). Серия без значка — пустая ячейка. Список получает
сведения о значке в `SeriesRowDto.Emblem` тем же запросом, проекцией без байтов.

**Публичный адрес** — `GET /api/series-emblems/{id}/{sha256}` (`SeriesEmblemsController`,
порт `ISeriesEmblemReader`, read-only контекст под ролью `swimm_ro`):

- хэш обязан совпасть с содержимым, иначе 404;
- `Cache-Control: public, max-age=31536000, immutable`, `X-Content-Type-Options: nosniff`,
  `Content-Type` — из базы (определён по сигнатуре при загрузке);
- адрес собирается в одном месте — `SeriesEmblemDto.PublicUrl(id, sha256)`;
- серверного кэша нет намеренно: запрос — одна строка по первичному ключу, ответ живёт в браузере.

**Синхронизация «прод → локально».** Таблица в `server/db/seed-tables.txt`, триггер версии
`Sys_DataVersion_Bump` — в миграции (правила 6 и 13 `pre-push-rules.md`), гранты `swimm_ro` и
`swimm_sync` — там же и в `02-grants.sql`. `bytea` едет штатно: `pg_dump` пишет его в `COPY`
текстом `\\x…`, `sync-merge.sql` сравнивает и переносит колонки без оглядки на тип. Цикла
внешних ключей нет: `SeriesEmblems` — родитель, `CompetitionSeries` — ребёнок.

## 3. Что проверено и что нет

Проверено 12.11.2026 локально (API на 5084, локальная база, встроенный браузер на Chromium):

- миграция применена, таблица, CHECK-ограничения, триггер версии и гранты на месте;
- в админке на пробной серии: тестовая эмблема Эйлата 1,7 МБ PNG → 512×512 WebP, 72 КБ;
  предпросмотр до отправки и после; замена; удаление значка (серия осталась); удаление серии
  (строка значка ушла вместе с ней, сирот нет); все пять действий — в аудите;
- публичный адрес: 200, `image/webp`, `immutable`, `nosniff`, SHA-256 ответа равен хэшу в адресе;
  чужой хэш и адрес заменённого значка — 404;
- строка контроллера на `/Admin/Cache` описана;
- тесты: 3712 из 3712;
- список серий (доработка, API на 5084): у пробной серии со значком — миниатюра 40 px, у серии
  без значка ячейка пустая; клик открывает окно с двумя картинками 288 px (тёмный и светлый фон),
  именем и размером, адрес страницы не меняется; окно закрывается крестиком, кликом по затемнению
  и Esc, клик по самой картинке его не закрывает; пробные серии удалены; тесты 3713 из 3713.
  Панель браузера была скрыта: открытие и закрытие проверены событиями из скрипта, вид — снимком
  при эмулированном окне 1280×800; настоящей мышью и клавиатурой не нажималось.

Файл в тестах подавался странице скриптом (в поле выбора), а не окном выбора файла — дальше шёл
настоящий путь: canvas, отправка формы, сервер. **Не проверено:**

- отказ сервера на «не картинку» через саму форму (браузер всегда шлёт уже перекодированный
  файл) — покрыто тестами `SeriesEmblemImageTests` и `SeriesEmblemPgTests`;

- живой прогон `/db-sync-from-prod` со значком: на проде таблицы ещё нет (скрипт сверяет версию
  схемы и до `--migrate` на проде откажет); перенос `bytea` выведен из чтения скриптов, не из прогона;
- ProdAdmin и прод-база — не трогались;
- Safari (кодирует ли canvas в WebP или отдаёт PNG) — сервер принимает оба.
