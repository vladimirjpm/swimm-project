## 5. Решения, которые нельзя переизобрести

- **Избранные — ДЕФОЛТ состава, а не сам состав.** Отметить можно кого угодно, включая
  чужой клуб; обратно в favorites это НЕ пишется.
- **«Плана нет» ≠ «сохранён пустой план».** В первом подставляем избранных, во втором
  человек снял всё сам. Поэтому `null` против пустых списков — не «пустота значит нет».
- **Карточка — главный экран таба**, открывается сама, как только состав известен; ссылку
  с `?swimmer=`/`?heat=` не перебивает.
- **Открытая share-ссылка НЕ перезаписывает план получателя** — своим состав становится
  после первой правки, тогда же `?plan=` уходит из адреса. Галочки в ссылку не едут.
- **Ручное и автоматическое — в разных полях.** Флаг чемпионата ставит забор
  (`IsChampionship`), админ правит `IsChampionshipOverride`; иначе идемпотентный перезабор
  затирал бы решение человека. Разминка — только руками.
- **Многодневка живёт на уровне СОБЫТИЯ.** Программы грузятся у всех источников: у
  составного чемпионата дни лежат по разным протоколам.
- **Строка D3 — не `SwimRow`** (правило хендоффа, откат 28.08.2026). Общие части взяты:
  `UI_SwimmStyleIcon`, `UI_SwimTime`.
- **Токены Deep объявлены на классе**, а не на `:root` — таб включает их сам
  (`theme-deep` / `theme-deep-light`); без этого весь дизайн рисуется пустыми переменными.
- **В метке строки «seed», а не «PB»** — посев это не результат (правило №1 хендоффа).
- **Времени нет = полночь в источнике** → «not scheduled», а не 00:00.
