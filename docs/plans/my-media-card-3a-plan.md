## 1. Решения Влада (12.11.2026)

- **Плита под иконкой стиля в тёмной теме — остаётся, 7% белого** (`--swim-plate` в `index.css`,
  правка 11.11). В макете плиты в тёмной нет — макет в этом месте НЕ переносим. Иконка —
  `surface="auto"`.
- **Порог двух панелей — 1280**, подтверждён. Расчёт дизайнера сходится с вёрсткой страницы:
  поля `.mm-panel` 48+48, padding 20+20, сайдбар 320, зазор 16 → карточка 808px.
- **Контур кнопок в тёмной — «как у нас принято»**: токены, которыми карточка красится сейчас
  (`--t-accent-border` у акцентных кнопок, `--t-border` у полей). Значений макета (24% белого)
  не переносим, новых ролей не заводим.
- **Кружок места 32px — ступень `medal-32`** в существующем `UI_MedalIcon` (сделано).

## 2. Как делать (что не видно из хендоффа)

- **Порог — по ширине карточки, а не окна.** Две панели включать container-query на карточке
  (≥ 808px), а не `@media (min-width: 1280px)`: ширину карточки определяет ещё и сайдбар
  фильтров, и медиазапрос по окну разойдётся с ней при первом же изменении сайдбара.
- **Место ≠ медаль.** `UI_MedalIcon` красит кружок по номеру. Медальную заливку давать только
  при `HelperResults.isMedalPlace(...)` (функция `medal()` в `swim-list.tsx` уже так считает);
  иначе — `styleType="icon-noplace"`: номер без кружка, цветом текста темы. В макете у места 5
  белый кружок с тенью — у компонента такого вида нет, берём имеющийся «номер без заливки».
- **Чего в макете нет, а на странице есть — ПЕРЕНОСИМ в новую раскладку, не выбрасываем:**
  статусы публикации и Share / Withdraw / Delete (`MediaLine`), строка `Under review`
  (`swimFlaggedRowProps`, Р76), `UI_PrelimLabel`, DNS/DQ (`HelperResults.failLabel`), 🎉 и ❤,
  заплыв без медиа («+ Add video»), медиа ко всему соревнованию (📎). Влад не возражал
  (12.11, вопрос был задан, ответа «убрать» не было) — перед сдачей показать, куда каждое легло.
- **Кнопки `YouTube cover`, `Poster`, `Cover or poster`** — точки входа без логики (задача 2).
  Решить при вёрстке: показывать выключенными с подсказкой или не показывать до задачи 2 —
  спросить Влада, кнопка «в никуда» на проде нежелательна.
- **Клуб в `MySwimDto`** (`server/Swimm.Application/Dtos/MySwimsDtos.cs`): сейчас его нет.
  Нужны id и ивритское название клуба пловца на момент заплыва — для `UI_ClubLogo` в шапке.
  У эстафеты владелец строки — нога, логотип брать у выбранного пловца.
- **Имя пловца в шапке — влево** (`items-start` у столбика в `CompetitionGroup` не потерять).
- **Порталу (выезжающая панель, шторка) нужен свой класс темы** — `useDeepThemeClass()`.
  Шторку брать с `MobileFiltersDrawer` / `DeepSheet`, свою не писать.

## 4. Как сделано (12.11.2026)

Устройство — `docs/media-page.md` «Карточка соревнования 3A». Здесь — отступления от
хендоффа и куда легло то, чего в макете не было.

**Отступления:**

- **Порог двух панелей — карточка ≥ 780px, а не 808.** Расчёт дизайнера (окно 1280 → 808) не
  учитывал полосу прокрутки окна: на 1280 в Windows карточка выходит 791–793px. С порогом 808
  подтверждённые «две панели на 1280» не включались бы.
- **Заплыв без медиа — «+» вместо «открыть медиа».** В макете кнопка одна у всех строк; у
  пустого заплыва она открывала бы пустую панель, а добавить видео к свежему заплыву —
  главный сценарий страницы (решение 26.10.2026).
- **Карточка без единого медиа — без панели**, список во всю ширину.
- **Кнопок `YouTube cover` / `Poster` / `Cover or poster` нет** — скрыты до задачи 2 (решение Влада 12.11.2026, §3).
- Лайтбокс `UI_SwimmerGallery` поднят с `z-50` на `z-110`: из выезжающей панели он
  открывался ПОД ней.

**Куда легло то, чего нет в макете:**

| Что | Где теперь |
|---|---|
| Статусы публикации, Share / Update, Withdraw, Delete (`MediaLine`) | панель медиа, под лентой превью — для выбранного медиа |
| «Кому видно» по всему заплыву (`RowVisibility`) | заголовок панели, справа |
| ❤ | в строке — сводка под временем (если не ноль); нажимаемое — в плашке источника в панели |
| 🎉 | под временем в строке и в заголовке панели (если не ноль) |
| `Under review` (Р76) | на строке (`swimFlaggedRowProps`), чип у времени — в строке и в панели |
| `UI_PrelimLabel` | под кружком места в строке; в подписи заголовка панели |
| DNS / DQ | на месте времени; место — прочерк |
| «+ Add video» у заплыва без медиа | пунктирный «+» на месте кнопки «открыть медиа» |
| «+ Add media» у заплыва с медиа | пунктирная плитка «+» в конце ленты превью |
| Медиа ко всему соревнованию (📎) | первая строка списка «Competition media» → та же панель; добавить — «+» в шапке |
| Колонка DATE (день разошёлся с шапкой) | день заплыва под временем |
| Подпись «50m breast» | ссылка в заголовке панели |

**Проверено в браузере** (персонаж `utest-parent`, ему в локальной базе заведены 2 видео и
3 фото): 1440 и 1280 — две панели, 1100 — выезжает справа, телефон 375 — шторка; светлая и
тёмная; режим All и один пловец (логотип клуба, RELAY, бронза); DNS / DSQ и карточки без
медиа — на аккаунте по умолчанию; лайтбокс поверх панели.

**Глазами НЕ проверено** (в локальной базе нет таких строк с медиа под рукой): `Under review`,
`[prelim]`, 🎉 и ❤ с ненулевым счётчиком, статусы pending / published / rejected и Withdraw в
панели, рекордный бейдж и SB. Код этих мест — прежние компоненты, перенесённые без правки.
