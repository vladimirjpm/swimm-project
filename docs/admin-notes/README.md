# docs/admin-notes — справки админки

Короткие пояснения «почему так» к службам и страницам админки: почему служба выключена, откуда
цифра, что будет, если нажать. В админке их открывает значок **«ⓘ»** рядом с названием — по
клику попап с этим текстом. Все справки одним списком — `/Admin/Docs/notes` («Справки админки»).
Как устроено — [admin-pages/admin-notes.md](../admin-pages/admin-notes.md).

**Добавить справку = положить сюда один MD-файл.** Код не правится: значок появляется сам, если
на странице уже стоит метка с этим ключом (у служб `/Admin/Jobs` — стоит всегда).

## Имя файла = ключ

`<ключ>.md`, ключ — латиница в нижнем регистре, цифры, точка и дефис (`[a-z0-9.-]`, без `..`).
Первая часть до точки — к чему справка:

| Префикс | К чему | Пример |
|---|---|---|
| `job.<ключ службы>` | служба на `/Admin/Jobs` — ключ из `JobNames` (`loglig-batch`, `discovery`, `start-list`…) | `job.loglig-batch.md` |
| `page.<страница>` | страница целиком — имя как у её MD в `admin-pages/` | `page.swimmers-loglig.md` |
| `setting.<параметр>` | параметр `/Admin/Settings`, имя в нижнем регистре через дефис | `ResultsAutoMode` → `setting.results-auto-mode.md` |

Префикс — договорённость для порядка, механизм смотрит только на ключ целиком.
`README.md` справкой не считается.

## Формат файла

```markdown
# Заголовок справки

Проверено: 20.11.2026

Текст в Markdown: абзацы, списки, таблицы, блоки кода, ссылки.
```

- **Первая строка — заголовок** `# …`: он же в попапе, в подписи значка и в списке Docs.
- **Вторая — «Проверено: ДД.ММ.ГГГГ»**: когда цифры и факты в справке последний раз сверяли с
  базой и кодом. Попап показывает дату; старше 90 дней — жёлтым «цифры могли устареть».
  Перепроверил — обнови дату.
- Дальше — обычный Markdown, движок тот же, что у `/Admin/Docs`. Сырой HTML выключен.
- Ссылки на другие MD (`../loglig-id-plan.md`) ведут внутрь `/Admin/Docs`; ссылки на страницы
  админки пиши от корня — `/Admin/Settings`.
- Секреты (ключи, пароли) в справку не писать — только где лежат.
- Пиши для Влада: что происходит, почему, что делать. В конце полезно «как перепроверить» —
  готовый SQL или где смотреть.

## Как поставить значок на странице

Одна строка разметки рядом с названием — в Razor или в строке, которую рисует скрипт:

```html
<h2 class="flex items-center gap-1.5">Пакетная привязка loglig-id <span data-note="job.loglig-batch"></span></h2>
```

Общий скрипт каркаса (`wwwroot/js/admin/admin-notes.js`) превращает метку в кнопку «ⓘ», если
справка с таким ключом есть, и прячет метку, если нет. Метки, дорисованные позже, подхватываются
сами. Внутри элемента, который сам кнопка или ссылка, вместо `data-note` — `data-note-mark`:
пассивная пометка «ⓘ» без кнопки (кнопка в кнопке — невалидный HTML).
