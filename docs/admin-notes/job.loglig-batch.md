# Пакетная привязка loglig-id: почему выключена

Проверено: 20.11.2026

**Коротко.** Служба выключена по умолчанию с самого начала (июль 2026), потому что она платная.
Её никто не отключал — её просто ни разу не включали.

## Что она делает

Берёт пловцов без привязки к loglig и для каждого ищет карточку игрока через поисковый сервис
[serper.dev](https://serper.dev) — это выдача Google по запросу `site:loglig.com "имя"`. Найденную
карточку сверяет с пловцом по имени и году рождения; совпало — привязывает.

## Почему платно

Каждый пловец — от 1 до 3 запросов к serper.dev, а запросы там покупаются.

## Что работает вместо неё

- **Кнопка «Батч ×20»** на [/Admin/Swimmers/Loglig](/Admin/Swimmers/Loglig) — тот же поиск, но
  вручную, порциями по 20 пловцов.
- **Главное — привязки приходят сами и бесплатно** из протоколов и старт-листов, где loglig-id
  напечатан.

## Сколько уже сделано

Прод-база на 20.11.2026: всего пловцов **6873**, привязано **6474**.

| Источник привязки | `LogligIdSource` | Пловцов |
|---|---|---:|
| из протоколов | `protocol` | 5995 |
| из старт-листов | `startlist` | 428 |
| вручную в админке | `admin` | 40 |
| автопоиск через serper.dev | `auto` | 7 |
| без источника | — | 3 |

Ночной батч на проде не запускался ни разу.

### Кто эти 400 непривязанных

| Кто | Пловцов | Поможет ли поиск |
|---|---:|---|
| с результатами, имя не на иврите | 195 | скорее всего нет: поиск идёт по ивритскому имени |
| с результатами, имя на иврите | 165 | **да — это единственные настоящие кандидаты** |
| локальные пловцы групп (`Origin = 'local'`) | 27 | нет: в loglig их нет по определению |
| без результатов | 12 | — |

## Аккаунт и ключ

- Аккаунт serper.dev есть.
- Ключ лежит в конфигурации разработки; для ProdAdmin — в `appsettings.ProdAdmin.Local.json`,
  параметр `CandidateSearch:ApiKey`.
- На App Service (прод) ключа нет и не должно быть: поиск идёт только из админки.
- Пустой ключ — поиск отключён, ручная привязка при этом работает.

## Условия serper.dev

⚠ Сверить на сайте перед покупкой — записано по состоянию на 20.11.2026.

- При регистрации бесплатно 2500 запросов, карта не нужна.
- Подписки нет — покупаются пакеты кредитов. Младший — $50 за 50 000 запросов ($1 за тысячу).
- Кредиты действуют 6 месяцев.
- Полный возврат в течение 7 дней, если потрачено меньше 20%.
- Один аккаунт на клиента.

## Вывод

На 165 кандидатов нужно 165–495 запросов — это укладывается в бесплатные 2500, если они ещё не
израсходованы. Ночной батч для этого не нужен: хватит 8–9 нажатий «Батч ×20», а остальных
привязки догонят из следующих протоколов.

## Как включить, если понадобится

1. Нужен ключ serper.dev у ProdAdmin (`CandidateSearch:ApiKey`, см. выше).
2. [/Admin/Settings](/Admin/Settings): `LogligBatchEnabled = true`.
3. Там же — порция за прогон `LogligBatchPerRun` (по умолчанию 50) и интервал
   `LogligBatchIntervalHours` (по умолчанию 24 — раз в сутки).

## Как перепроверить цифры

Привязки по статусу и источнику:

```sql
SELECT COALESCE("LogligIdStatus", '—') AS status,
       COALESCE("LogligIdSource", '—') AS source,
       count(*)                         AS swimmers
FROM "Swimmers"
GROUP BY 1, 2
ORDER BY 3 DESC;
```

Непривязанные по группам (как в таблице выше):

```sql
SELECT CASE
         WHEN s."Origin" = 'local'                         THEN 'локальные пловцы групп'
         WHEN NOT EXISTS (SELECT 1 FROM "Results" r
                          WHERE r."SwimmerId" = s."Id")    THEN 'без результатов'
         WHEN s."LastName" ~ '[א-ת]'
           OR s."FirstName" ~ '[א-ת]'                      THEN 'с результатами, иврит'
         ELSE 'с результатами, не иврит'
       END AS who,
       count(*) AS swimmers
FROM "Swimmers" s
WHERE s."LogligId" IS NULL
GROUP BY 1
ORDER BY 2 DESC;
```

Прогоны службы (ночные и кнопкой «Батч ×20» — у кнопки `Trigger = 'manual'`):

```sql
SELECT "StartedAt", "Trigger", "Success", "Summary", "Error", "RunBy"
FROM "Sys_JobRunLog"
WHERE "Name" = 'loglig-batch'
ORDER BY "StartedAt" DESC
LIMIT 20;
```
