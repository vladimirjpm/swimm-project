## 4. B5: даёт ли источник ID пловца?

Проверено 2026-07-15 (поток B): isr.org.il публикует результаты через loglig.com
(iframe на comp.asp), PDF-протокол добывается экспортом
`loglig.com/Leagues/ExportSwimmingCompetitionResults?competitionId=<logligId>` и
парсится существующим IsrOrgParser (смоук пройден). **ID пловца в PDF-протоколе НЕТ** —
матчинг при импорте остаётся по (LastName, FirstName, BirthYear).
Перспектива: HTML-страницы loglig `LeagueTable/AthleticsDisciplineResults/<id>` могут
содержать ссылки на карточки атлетов с внутренними id loglig — если понадобится
системный дедуп, копать туда (отдельная задача, не в этом потоке).
