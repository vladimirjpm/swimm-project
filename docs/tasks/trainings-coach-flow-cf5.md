# CF5. План по занятию

План: `docs/plans/trainings-coach-flow-plan.md`. Макеты: `!design_handoff/design_handoff_trainings_coach_flow/` — нет.

## Правила (полный текст — §0 плана)

1. Существующее важнее подготовленного: если в проекте уже есть компонент, модуль, стиль, токен или
   паттерн для той же цели — используется он, даже если макет или эта задача описывают иначе.
2. Не создавать новые визуальные компоненты, модули, CSS-файлы, цвета и токены, пока не проверено,
   что подходящего нет (`docs/ui-components.md`, `components/deep/`, `components/mix/`, компоненты
   группы, витрина `dev/ui-kit/registry.tsx`).
3. Не нашёл подходящего — остановиться и спросить владельца проекта, назвав варианты.
4. Макеты — схема состава и раскладки. Цвета, шрифты, радиусы и вид контролов с них не копировать.
5. Цвета только токенами `var(--deep-*)` (и `--t-*` там, где так у соседей). Никаких hex / rgb.
6. Светлая и тёмная тема: проверить в `theme-deep` и `theme-deep-light`; порталы получают класс
   темы через `useDeepThemeClass()` или идут через `DeepSheet`.
7. Формы — `DeepSheet` + реестр `trainings-sheets.tsx`; подтверждения — `ConfirmDialog`.

## Зачем

План дорожек адресуется датой: можно создать план на день без тренировки, а две тренировки одного дня делят один план.

## Что сделать

1. Сервер: план адресуется id занятия — `/lane-plans/{sessionId}`, тот же ключ, что у `/rsvp/{id}`.
   Все ручки плана (`get`, `save`, `away`, `publish`, `unpublish`, `remove`, раскладка) переходят на него.
2. `LanePlanSummary` и `LanePlan` получают `session_id`; `date` остаётся.
3. Миграция существующих планов — по §5.1 плана.
4. Клиент: `lane-plans-api.ts`, контекст таба (`lanePlans`, `upcomingPlans`), рабочий стол и вид Lanes
   участника переходят на новый ключ. Участник листает опубликованные планы занятий.
5. Тренер не может создать план на день без занятия.

## Файлы

- сервер — сущность плана, ручки, миграция
- `lane-plans-api.ts`, `../types.ts`, `trainings/trainings-context.tsx`, `group-lanes.tsx`

## Не делать

- Не терять и не изменять содержимое существующих планов при миграции.
- Не ломать адреса, по которым участники открывают Lanes.

## Готово, когда

- У двух занятий одного дня разные планы.
- Старые планы открываются у своих занятий; план на день без занятия доступен только для чтения.
- «Copy from …» предлагает прошлые занятия.
- Телефон (390) и десктоп (≥ 960): ничего не обрезано, горизонтальной прокрутки страницы нет.
- Обе темы: `theme-deep` и `theme-deep-light` — текст читается, нет «пустых» цветов у порталов.
- В изменённых файлах нет hex / rgb-цветов и новых CSS-файлов.
- Участник открывает опубликованные планы как раньше.
- Сборка, линтер и тесты проекта проходят.

## Спросить до начала, если

- в базе есть планы на даты с несколькими занятиями или без занятий — показать их число и решить
  с владельцем до миграции.
