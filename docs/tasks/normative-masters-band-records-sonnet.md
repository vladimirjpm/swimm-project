# Этап 11.4 — рекорды ПОЛОСЫ в попапе нормативов мастерсов (задание Sonnet)

## Контекст

Попап «Normative Info» (`client/src/projects/components/popup/popup-content-normative.tsx`)
показывает лестницу нормативов и две колонки рекордов: **World** (`WR`) и **Israel** (`NR`).
Для мастерсов у попапа есть переключатель полосы возраста (`selectedAgeGroup`, «25-29»,
«30-34»…), и лестница нормативов под него перестраивается, а колонки рекордов — НЕТ: на
«Freestyle · 25-29» печатаются абсолютные рекорды (мировой 19.90, израильский 21.08), и они
не меняются при переключении полосы. Для мастерса это бессмысленно — сравнивать себя надо с
рекордом своей полосы.

Причина: `getRecordCell` берёт запись по ключу `пол → бассейн → стиль → дистанция → WR|NR`,
возраста в ключе нет, а дерево `recordsTree` — это `RecordsHelper.getOpenRecords()`, только
категория `open`.

Данные для исправления уже лежат в базе и сходятся: израильские мастерские рекорды
(`country/ISR/masters`, 845 строк) и мировые мастерские (`world/masters`, 1095 строк, полосы
25-29 … 105-109). Проверено 17.09.2026: у каждой из 845 израильских строк есть пара в
`world/masters` по той же полосе, ключ полосы одинаковый («25-29»), маппинг не нужен.
Подробности — `docs/plans/records-handoff.md`, пункт 1 раздела «Что дальше»; этап в
`docs/ROADMAP.md` — 11.4.

## Решения (зафиксированы, не пересматривать)

1. **В режиме мастерсов** (`isMastersBool === true` и выбрана полоса `selectedAgeGroup`)
   колонка **World** показывает мировой мастерский рекорд ЭТОЙ полосы (`world/masters`), а
   колонка **Israel** — израильский мастерский рекорд ЭТОЙ полосы (`ISR/masters`).
2. **Полосы нет в оси — клетка ПУСТАЯ (прочерк «—»). Никакого отката на абсолютный рекорд.**
   Решение Влада 18.09.2026. Молчаливый откат — ровно та беда, которую чиним: на «25-29»
   показывался бы абсолютный рекорд, неотличимый от рекорда полосы. Прочерк уже умеет
   рисовать `Helper.formatSecondsToTimeString(Infinity)` → «—», отдельной вёрстки не нужно.
3. **Эстафеты** в мастерских рекордах не берём (их нет ни в одной оси) — отдельной обработки
   не нужно, для них клетка просто окажется пустой по правилу 2.
4. **Не-мастерский режим не меняется ни на символ**: там как было — `getOpenRecords()`,
   абсолютные рекорды.
5. **Подпись над колонками** в режиме мастерсов уточняется: вместо «World» / «Israel» —
   «World · 25-29» / «Israel · 25-29» (текущая полоса). Видимый UI — только английский.
   Так пользователь видит, что колонка переключилась, а не гадает.
6. Мировые мастерские рекорды грузятся **в `RecordsHelper`, по образцу существующих
   загрузчиков**, а не отдельным `fetch` в попапе: у попапа все рекорды из одного места.

## Шаги

1. **`records-helper.ts`:**
   - параметризуй регион у `loadCategoryAsAgeTree(category, region = HOME_REGION)` (вызовы
     `age` и `masters` поведение не меняют);
   - добавь кэш `worldMastersCache`, загрузчик `loadWorldMastersRecords()` →
     `loadCategoryAsAgeTree('masters', 'world')`, геттер `getWorldMastersRecords(): AgeRecordsTree`
     (пустое дерево до загрузки — как у остальных), очистку в `clearCache()` и запуск в
     `warmUp()`;
   - комментарии — по-русски, в стиле соседних загрузчиков.
2. **`popup-content-normative.tsx`:**
   - заведи функцию получения клетки мастерсов: из дерева `AgeRecordsTree` по
     `gender → poolType → stroke → distance → selectedAgeGroup`. **Без фоллбека на 50м
     бассейн**: `getRecordCell` сейчас подставляет 50м, если нет 25м, — для мастерсов так
     нельзя (решение 2), нет клетки — `null`;
   - в `fmtRecord` и в подсчёте `recordsUpdatedLabel`: если режим мастерсов и полоса выбрана —
     брать клетку из мастерских деревьев (`WR` → `getWorldMastersRecords()`, `NR` →
     `getMastersRecords()`), иначе — прежний `getRecordCell` по открытым;
   - формы клеток разные (`OpenRecordCell` / `AgeRecordCell`), но `fmtRecord` использует только
     `time`, `name`, `updated_at` — они есть в обеих; приведи к общему минимальному типу, не
     плоди `any`;
   - подпись колонки (сейчас `kind === 'WR' ? 'World' : HOME_REGION_LABEL`, ~стр. 564): в
     режиме мастерсов дописывать ` · ${selectedAgeGroup}`;
   - деревья мастерсов грузятся асинхронно — попап должен перерисоваться, когда они
     придут. Посмотри, как это уже сделано для `getOpenRecords()` (или `getMastersStandards()`
     — лестница мастерсов тоже асинхронная) и повтори тот же механизм.
3. Прогони `npx tsc --noEmit` в `client/`.

## Footguns

- **Build-lock**: если `dotnet build` падает с `MSB3027`/`MSB3021` «locked by .NET Host» —
  жив прежний `dotnet run`/`preview`; найди его `Get-CimInstance Win32_Process` и убей, либо
  собирай с `--configuration Release`.
- `preview_stop` иногда не добивает процесс — та же картина.
- **Ось возраста.** Полоса мастерсов в справочнике — строка вида «25-29», у мира полосы идут
  до «105-109» (трёхзначные). В попапе есть регекс `^\d{2}-\d{2}$` для распознавания групп
  НОРМАТИВОВ — к рекордам он не относится, не трогай его и не завязывай выбор клетки на него.
- `RecordsHelper` — статический класс с кэшами; геттер до загрузки обязан вернуть пустое
  дерево, а не `null` (как соседние), иначе попап упадёт на первом рендере.
- Имена держателей — ивритские по умолчанию, латиница — фоллбек (CLAUDE.md). Держатель тут
  только в `title`, но не меняй порядок.
