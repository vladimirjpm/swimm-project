## Решения (зафиксированы, не пересматривать)

1. **Загрузка сезона**: пока данных сезона нет — строка управления видна (‹ › disabled),
   вместо тела вида — блок `min-height 320px` с текстом `Loading calendar…` (13px, `--t-text-2`),
   `aria-busy="true"` на контейнере календаря. Повторный заход в загруженный сезон — без
   мигания (кэш Б2). Ошибка — `Could not load the calendar.` + кнопка `Try again` (повторить
   запрос; кэш ошибку не хранит).
2. **Пустые состояния** — тексты дословно по §4; проверь все пять мест: день без meets (Month,
   десктоп и телефон), месяц без meets (Month — под сеткой; Meet days — вместо сетки), карточка
   месяца без meets (Year: 0 + `No championships`), фильтр оставил 0 (те же тексты), сезон без
   meets (Year disabled, Month — пустая сетка + «No meets this month»).
3. **Disabled-виды** — по §4: `aria-disabled="true"`, `opacity .45`, `cursor:not-allowed`,
   клик/Enter/Space ничего не делают, но кнопка остаётся в порядке Tab (чтобы экранная читалка
   объявила её). То же у ‹ › на границах.
4. **Клавиатура** в сегменте видов (radiogroup): ←/→ переключают выбранный вид (пропуская
   disabled), `tabIndex=0` только у выбранного, у прочих `-1` (roving tabindex). Чипы типов —
   обычные кнопки с `aria-pressed`. Ячейки дня, карточки месяцев, тайлы ленты — `button`
   (Enter/Space работают сами); если где-то `div role="button"` — заменить на `button`.
5. **Фокус**: у КАЖДОГО кликабельного элемента календаря и полосы Records — видимое
   `:focus-visible` (`outline 2px solid var(--t-accent); outline-offset 2px`). Ячейки, у которых
   уже есть `outline` для «сегодня»/выбранного, — фокус через `box-shadow: 0 0 0 2px var(--t-surface),
   0 0 0 4px var(--t-accent)`, чтобы не спорить с их обводкой.
6. **RTL-имена**: каждое название meet (плашка ячейки, куб, aria-label не трогаем) — `dir="auto"` (латинские имена вроде «Maccabiah 2026» иначе режутся с начала)
   + `text-left`; площадка — `dir="auto"`. Проверь, что многоточие плашки стоит в конце строки
   иврита (слева), а сама плашка выровнена по левому краю ячейки.
7. **Объявления**: контейнер кубов дня и ленты Meet — `aria-live="polite"` (уже должно быть с Б4 —
   проверь); заголовок периода (`October 2026`) — `aria-live="polite"`, чтобы ‹ › объявлялись.
