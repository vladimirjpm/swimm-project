## 3. Решения (зафиксированы, не пересматривать)

1. Каждая карточка — отдельный файл в `components/`, подключается в `club-project.tsx`
   в порядке макета: **Standings → Competition timeline → Top swimmers → Swimmers →
   Record wall → Coaches**.
2. Карточка читает **общий скоуп** и своих фильтров не заводит. **Единственное исключение** —
   Record wall: у неё локальный `.deep-seg` All/25m/50m (25м и 50м физически несравнимы).
3. Цвета — **только** `var(--deep-*)`, никаких хардкодов hex и никаких tailwind-цветов
   (`text-gray-500` и т.п. запрещены — они не переключаются вместе с темой). Роли:
   accent = мы/CTA/❄ winter, gold = медали/#1/☀ summer, `--deep-ow` = открытая вода,
   `--deep-danger` = DSQ. **Один glow на карточку.**
4. **UI строго на английском** (данные — на иврите, это нормально).
5. Пустое состояние — **норма, а не край**: карточка без данных рисует осмысленную строку
   («No records yet»), а не исчезает и не падает.
6. **Coaches и фото клуба — карточка рисуется ПУСТОЙ** с подписью, что данных пока нет:
   тренеров в БД не существует вовсе (решение Влада 2026-08-01). Не выдумывай источник.

## 4. Карточки

### 4.1 Standings (`club-standings.tsx`)
Данные: `data.standings` (может быть `null`).
Заголовок: `❄/☀ · группа · сезон · N clubs`. Строки — `.deep-stand-row`, наш клуб
дополнительно `.deep-stand-row--us`. В строке: ранг (крупно, `#1` — gold) · имя клуба
(+ под ним `N swimmers · N scoring swims`) · справа очки и медали `🥇n 🥈n 🥉n`.
Сервер уже отдаёт нужное окно строк (лидеры + наш ± 1) — **не фильтруй повторно**.
⚠ Футер «N competitions left» из макета **НЕ делать** — под него нет данных.

### 4.2 Competition timeline (`club-timeline.tsx`)
Данные: `data.timeline`. Вертикальная линия: ранг-чип (`#1` — gold + единственный glow) ·
бейдж `❄/☀ · группа` (рисуется ТОЛЬКО если `kind != null`) · название соревнования
(ссылка на `/competitions/{competition_id}`) · дата · очки · медали.

### 4.3 Top swimmers (`club-top-swimmers.tsx`)
Данные: `data.top_swimmers` (уже топ-5, отсортирован). Строка: ранг · аватар-кружок с
инициалами (цвет по полу: `--deep-male` / `--deep-female`) · имя (ссылка на
`/swimmers/{swimmer_id}`) · возраст и медали · очки.

### 4.4 Swimmers (`club-swimmers.tsx`)
Данные: **новый хук** `client/src/hooks/useClubRoster.ts` → `GET /api/clubs/{id}/roster`.
Параметры: `page`, `pageSize`, `gender`, `ageFrom`, `ageTo`, `season`.
Ответ: `{ page, page_size, total, has_more, data: [{ swimmer_id, last_name, first_name,
last_name_en, first_name_en, birth_year, age, gender, competitions, swims }] }`.
Узкий список (≤440px): пилюли возрастов `All · 8–11 · 12–14 · 15–16 · 17+` **со счётчиками**
+ пилюли пола ♂/♀. Строка: аватар · имя (ссылка на пловца) · `age N` · `N comps`.
Футер «Show all N» — догружает следующую страницу.
⚠ Возрастные пилюли — это НЕ зачётные группы: у них свои границы, к `group` из скоупа они
отношения не имеют. Сезон в запрос передавай из скоупа (`season`), если он выбран.

### 4.5 Record wall (`club-records.tsx`)
Данные: **новый хук** `client/src/hooks/useClubRecords.ts` → `GET /api/clubs/{id}/records?pool=`.
Ответ: `{ data: [{ style_name, distance, pool_type, gender, time_original, time_ms,
swimmer_id, swimmer_name, swimmer_name_en, competition_name, date, points }] }`.
Заголовок + `.deep-count-badge` «N RECORDS» + локальный `.deep-seg` All/25m/50m.
Грид 3×N тайлов `.deep-record-tile--m` / `--f`: дисциплина, время (крупно), имя пловца
(ссылка), год, ♂/♀ в углу. При режиме All к дисциплине добавляется суффикс `· 25M`/`· 50M`.

### 4.6 Coaches (`club-coaches.tsx`)
Пустая карточка: заголовок «Coaches» + строка вида «Coach data is not collected yet».
Ничего не запрашивает.

## 5. Мобайл (390)

Те же карточки одной колонкой, тот же порядок. Standings без под-строки и медалей,

6. консоль браузера чистая;
7. ширина 390 — одна колонка, горизонтального скролла страницы нет.

Для клуба без данных проверь `/clubs/1291` — карточки должны показать пустые состояния,
а не упасть.

## 7. Footguns

- **Build-lock:** Visual Studio держит Debug-выход `Swimm.API`. Сервер собирай
  `--configuration Release`, API поднимай на :5079. **Чужие процессы не убивать.**
- **Vite может занять другой порт** (5173 бывает занят) — смотри вывод dev-сервера.
- **Правило парных токенов:** текст на тем-зависимой поверхности красится ТОЛЬКО парным
  токеном той же поверхности. Контраст ≥ 4.5:1 в обеих темах.
- Ссылки строй через `routes.*()` из `client/src/utils/routes.ts`, не хардкодь `.html`.
- Имена клубов и соревнований — на иврите (RTL) вперемешку с цифрами: не ломай выравнивание,
  используй `truncate`/`min-w-0` там, где строка может быть длинной.
