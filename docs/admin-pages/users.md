## Лимит групп (2026-09-10)

Колонка **«Группы»** — `владеет / действующий лимит` (`∞` у админа), бейдж «перс.» — у
пользователя стоит персональное исключение. Действующий лимит считается тем же правилом, что
проверка при создании (`HubGroupCreationRules`), поэтому колонка не расходится с тем, что видит
пользователь в панели «My groups».

В панели деталей (`?userId=`) — поле **«Персональный лимит»** (`AppUser.HubGroupLimit`,
хендлер `SetHubGroupLimit`): пусто — лимит по роли (`HubGroupMaxPerUser` / `HubGroupMaxPerCoach`
в /Admin/Settings), `0` — запретить создавать группы, потолок 100. Кнопка «Снять» возвращает к
лимиту по роли. Пишется в аудит как `user.hubgroup-limit`; сессии не отзывает — лимит не в
claims, проверка читает его из БД.

Считаются группы, которыми пользователь владеет, официальные тоже. Персональный лимит не
обходит политику `HubGroupCreationPolicy`. Полное правило — `docs/hubgroups-architecture.md` §3а.
