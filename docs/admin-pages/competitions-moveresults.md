# /Admin/Competitions/MoveResults — перенос результатов между соревнованиями

Файлы: `Pages/Admin/Competitions/MoveResults.cshtml(.cs)`;
сервис `IResultTransferService` (`ResultTransferService`). Ссылка — с тулбара
`/Admin/Competitions` («Перенос результатов»).

## Что делает (фаза 7.3, массовая операция)

Переносит **все** результаты соревнования-источника в соревнование-цель — для
склейки дублей-соревнований (например DbOnly-импорт + отдельно заведённый день).
Двухшаговый по паттерну проекта: **dry-run превью** (GET с обоими Id) →
**применение** (POST, с confirm).

## Что переносится / правила

- `ResultRecord.CompetitionId` → цель; денормализованная `CompetitionDate`
  обновляется на дату цели (парс `dd/MM/yyyy`).
- Эстафеты (`Relay`) и галереи едут **вместе** со своими результатами — они
  завязаны на результат (`RelayId`/`GalleryId`), не на соревнование.
- `CategoryCompetitions`, `Sys_ImportHistory`, `CompetitionResultUrls` **не**
  переносятся (привязаны к соревнованию/OrgCompId, а не к результату).
- **Дубли**: превью считает `OverlapCount` — индивидуальные заплывы источника,
  чей (пловец, стиль, дистанция) уже есть в цели. >0 — предупреждение (перенос
  не запрещаем: у разных категорий одного события пересечений быть не должно).
- Один `SaveChanges` = одна транзакция; после применения `InvalidateAllAsync()`.
- Аудит (7.4): `competition.transfer-results` со снимком отчёта.
- Источник после переноса **пустеет** — удаляется отдельно на странице Competitions.

## Не входит

Валидации «это точно один турнир» нет — ответственность админа (превью для того и
есть). Пересчёта клубных очков/рекордов перенос не делает.
