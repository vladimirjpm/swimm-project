# /Admin/UiPreview — витрина компонентов

Файлы: `Pages/Admin/UiPreview.cshtml`.

Образцы карточек/кнопок/таблиц админки — смотреть сюда при вёрстке новых страниц,
чтобы переиспользовать готовые Tailwind-классы (и не пересобирать бандл).

**Загрузка (08.10.2026).** Одно колесико на всю админку — класс `admin-spinner` (`Styles/admin.css`,
цвет — текущий цвет текста, размер — утилитой `size-5`). Занятая кнопка — `adminBusy(btn, on, text)`
из `_Layout.cshtml`: ставит `aria-busy="true"` (колесико перед текстом через CSS) и `disabled`,
снятие возвращает прежнюю подпись. Первые пользователи — пакетное затягивание и стартовый
протокол на `/Admin/Competitions`, колесико импорта на `/Admin/Import` и прогона по странам на
дашборде. Новую долгую кнопку переводить так же, а не рисовать своё колесико.
