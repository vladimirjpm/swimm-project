# /Admin/Results — ручная правка результата

Файлы: `Pages/Admin/Results/Index.cshtml(.cs)` (переход по Id),
`Edit.cshtml(.cs)` (форма); репозиторий `IResultAdminRepository`
(`ResultAdminRepository`); парс времени — `SwimTime` (Application/Mapping).

## Что делает

Точечное исправление **одной строки результата** (опечатка протокола) вместо
переимпорта всего соревнования. Index — переход к форме по `Id` результата
(виден в браузере данных Admin/Api). Edit — правит: время, место / место в
возр. группе, heat, lane, очки, дистанцию, пол, возр. группу, EventStyleAge,
дисквалификацию (флаг + пометка), заметку; плюс переназначение пловца/клуба по Id.

## Ключевые правила (security-sensitive)

- Меняет **публичные данные** → после сохранения `ICacheService.InvalidateAllAsync()`
  (репозиторий) + запись в аудит (7.4): `result.edit` со снимком `{before, after}`.
- **Время**: текст `м:сс.дд` / `сс.дд` → мс через `SwimTime.ParseToMs` (та же логика,
  что в импорте). Пусто → время снимается (null). Непарсящийся ввод — ошибка, а не
  тихое обнуление. Обратно мс → текст через `SwimTime.FormatMs` (сотые).
- **Эстафетные строки** (`RelayId != null`) не правятся — состав живёт в RelayMembers,
  переназначение пловца порвало бы связь.
- Переназначаемые пловец/клуб валидируются на существование (FK `Restrict`).
- Числовые поля проверяются под check-констрейнты БД (Heat/Lane ≥ 0, Position > 0/null,
  очки ≥ 0) — понятная ошибка до SaveChanges.
