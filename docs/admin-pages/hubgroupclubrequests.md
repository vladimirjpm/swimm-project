# /Admin/HubGroupClubRequests — заявки на статус клуба

Файлы: `Pages/Admin/HubGroupClubRequests/Index.cshtml`;
сервис `HubGroupClubRequestAdminService`.

Заявки владельцев групп на официальный статус клуба: просмотр, approve/reject.

**Approve** (2026-09-10): группа становится официальной группой клуба, заявитель получает роль
Coach — и после этого группа **сама подписывается на свой клуб**, если подписки у неё ещё нет:
состав наполняется пловцами клуба (выступавшими за него в текущем или прошлом сезоне). Без
этого одобренная группа стояла пустой — официальный статус это связь с клубом, не состав.
Подписку на другой клуб, выбранную владельцем раньше, одобрение не трогает. Сбой подписки
одобрение не откатывает (пишется в лог). Модель — `docs/hubgroups-architecture.md` §4а, §5.

**Последствия для других групп** (П4, 2026-09-10) — у pending-заявки под кнопками:
«Уйдут из каталога: N» (группы, подписанные на этот клуб; по ссылке работают) и «Будут
переименованы: M» (любые неофициальные группы, чьё имя совпало с клубом или с этой группой, —
« · community»; «старое → новое» — в подсказке строки). Считает `GetAllAsync`, одобрение
делает ровно это в той же транзакции и пишет аудит `hubgroup.official.approve` с перечнем.
Писем владельцам не шлём — у них плашка в «My groups».
