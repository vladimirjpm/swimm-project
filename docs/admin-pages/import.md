# /Admin/Import — импорт данных

Файлы: `Pages/Admin/Import.cshtml`; API: `/api/admin/import` (+`/status/{id}`,
`/clear`), `/api/admin/parse-pdf`, `/api/admin/import-parsed`,
`/api/admin/records/apply`, `/api/admin/clearable-tables`.
Сервисы: `JsonImportService`, `ImportJobQueue` (+`ImportBackgroundService`),
PDF — `Swimm.Parsing` (PdfPig).

Импорт соревнований из JSON (наш формат isr.org.il) и PDF-протоколов; привязка к
событию (EventId), очистка таблиц, импорт рекордов через diff. Задания идут через
очередь с фоновым воркером — статус опрашивается.

⚠ Инварианты данных, правила переимпорта и журнал инцидентов импорта —
[docs/data-integrity.md](../data-integrity.md). Читать перед правкой импорта или парсера.

## Заголовок заплыва без пола и возраста («שומרי שבת»)

Обычный ивритский заголовок — `<дистанция> <стиль> - <пол> <возраст>`
(«200 חופשי - בנים 13»). Но бывает текстовая категория:
`200 חופשי - שומרי שבת מוקדמות צעירים` — заплывы для соблюдающих субботу, куда заявляют
и мальчиков, и девочек любого возраста. Ни пола, ни возраста в шапке нет.

⚠ **До 2026-08-02 такой заголовок не брал ни один шаблон и молча игнорировался** —
событие не менялось, и результаты дописывались в ПРЕДЫДУЩИЙ заплыв. В протоколе
«מוקדמות אליפות הגילאים חורף 2025 מחוז צפון» (loglig 11792) 200 и 800 вольным уехали
в эстафету 4X50 комплексом: 20 личных результатов легли со стилем `individual_medley`,
дистанцией `4X50` и мужским полом у девочек.

Теперь есть фоллбеки `HeaderRxHECategory` / `RelayHeaderRxHECategory` (после основных
шаблонов, поэтому обычные заголовки разбираются как раньше). Личный вариант срабатывает
только на **известном стиле** из `StyleMapHE` — иначе шаблон подобрал бы любую строку с дефисом.
Категория → `EventStyleAge` («שומרי שבת» → `shabbat` → `EventCategory = mix-shabbat`),
возраст пустой, пол — `none`.

**Пол берётся с пловца** (`JsonImportService.ResolveResultGender`): он известен по остальным
его заплывам. Если неизвестен — результат остаётся без пола и виден в «Аномалиях» на
[/Admin/Results](results.md) (`?filter=no-gender`). В карточку пловца `none` НЕ пишется:
это отсутствие данных, а не пол, и один смешанный заплыв не должен портить человека навсегда.

⚠ **Эстафеты из этого добора исключены — и это не вкусовщина.** `Gender` входит в ключ
upsert (`ResultMatcher.KeyOfPersisted`: comp + style + distance + **gender** + heat + lane +
isRelay). Первая версия фикса подставляла пол «владельца» строки и эстафетам — переимпорт
перестал узнавать собственные строки микс-эстафет (`none` ≠ `male`) и вставил их заново:
в соревновании 1520 стало 1024 результата вместо 946. Лечится переимпортом с «удалять
лишние». Общее правило: **менять поле, входящее в ключ upsert, — значит порождать дубликаты
при следующем переимпорте.**

Побочно закрыт смежный дефект: разбор состава эстафеты сканировал строки вперёд до набора
всех ног и **не останавливался на заголовке следующего события** — эстафета с недобранным
составом съедала следующий заплыв целиком (год рождения в строке результата выглядел как год
ноги). Теперь скан прерывается на любом заголовке (`IsAnyEventHeaderHE`).

## Правила начисления очков при импорте (Э5)

Два селекта («Клубные очки» и «High Point») в общем блоке настроек — он один на
JSON- и PDF-ветку, как категории и привязка к событию. Дефолт — **«Авто»**:
правило подберётся по дате и типу соревнования (`CompetitionRuleResolver`), кроме
правил с пометкой `manual` — те работают только по явной привязке. Список правил —
[pointsrules.md](pointsrules.md).

- Выбранные Id едут через `ImportEventOptions.PointRuleClubsId` /
  `PointRuleSwimmersId` (JSON-ветка — поля формы, PDF-ветка — поля
  `ImportParsedRequest`) и проставляются в `JsonImportService` **каждому созданному
  соревнованию**: правило хранится у соревнования, а не у события, поэтому у
  многодневки его получает каждый день.
- **Переимпорт существующего соревнования привязку не меняет** — соревнование уже
  есть в БД, ветка создания не выполняется. Менять привязку осознанно — на
  /Admin/Competitions (в форме дня, кнопкой «всем дням события» или массово на
  `/Admin/Competitions/AssignRules`).
- Выбор не обязателен: «Авто» оставляет поведение, которое было до Э5.
