# /Admin/Docs/{section} — документация репозитория

Файлы: `Pages/Admin/Docs.cshtml`, `Pages/Admin/Docs.cshtml.cs` (`DocsModel`, `DocsRenderer`),
каталог разделов — `Pages/Admin/Shared/DocsCatalog.cs`. Стили отрендеренного MD — класс
`.admin-md` в `Styles/admin.css`. Рендер — Markdig (NuGet `Markdig`).

## Что показывает

Раздел сайдбара **«Документация»** (решение Влада 11.09.2026) с тремя подкатегориями:

| Пункт | Маршрут | Что внутри |
|---|---|---|
| Important | `/Admin/Docs/important` | [important.md](../important.md) — выжимка правил и решений на одну страницу; README, роадмап, рабочие планы |
| Rules | `/Admin/Docs/rules` | CLAUDE.md-гайды, правила перед push, конвенции кода, сезон, реестр компонентов, карта админки |
| Decisions | `/Admin/Docs/decisions` | архитектура, целостность данных, места и медали, эстафеты, медиа, кэш, «клуб — не группа» |

Слева — список документов раздела, справа — выбранный документ (по умолчанию первый) с
датой последнего изменения файла. `/Admin/Docs` без раздела уводит на Important.

## Как устроено

- **Копий нет**: MD читается с диска при каждом открытии, поэтому совпадает с репозиторием.
  Правят документы в репозитории; админка только показывает.
- **Ссылки между документами работают**: относительная ссылка на `.md` (`plans/…`, `../CLAUDE.md`)
  переписывается в `/Admin/Docs/{раздел}?file=…`. Ссылки на исходники (`.cs`, `.tsx`) остаются
  как есть и в админке не открываются.
- **Что можно открыть** — только MD под `docs/` и белый список (`README.md`, `CLAUDE.md`,
  `AGENTS.md`, `client/CLAUDE.md`, `server/Swimm.Application/CLAUDE.md`,
  `.github/copilot-instructions.md`); выход вверх (`..`) и прочие файлы — отказ с пояснением.
- **Сырой HTML в MD выключен** (`DisableHtml`): рендер идёт в страницу админки.

## Как поддерживать

- Новый ключевой документ → строка в `DocsCatalog.Sections` нужного раздела.
- Новое правило или решение Влада, которое нельзя потерять → пункт в
  [important.md](../important.md) со ссылкой на источник (правило файла: без источника пункт не пишется).
- Оба пункта — в [pre-push-rules.md](../pre-push-rules.md).

## Грабли

- **Корень репозитория ищется подъёмом от ContentRoot** (папка с `docs/` и `CLAUDE.md`). В
  опубликованной сборке файлов документации нет — страница пишет это вместо текста. Нужна
  документация на проде — копировать MD в publish (решение при деплое).
- Стили `.admin-md` в бандле: после правки `Styles/admin.css` — `npm run css:build`. Ссылка на
  бандл в `_Layout` идёт с `asp-append-version` — без хэша браузер держал старый CSS, и новые
  стили «не применялись».
