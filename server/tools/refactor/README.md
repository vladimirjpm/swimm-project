# Инструменты рефакторинга (деление больших методов)

Приёмы и журнал шагов — [`docs/plans/refactor-handoff.md`](../../../docs/plans/refactor-handoff.md).
Здесь — то, что пригодилось больше одного раза. Python в Git Bash звать полным путём
(`C:/Users/Vlad/AppData/Local/Python/pythoncore-3.14-64/python.exe`): `python` резолвится в
заглушку Microsoft Store. Скрипты на C# — file-based (`dotnet run file.cs -- …`), запускать из этой папки.

| Файл | Зачем | Где выручил |
|---|---|---|
| `split_try_chain.py` | Метод `Try…` с телом `if (cond) { подблок; подблок; … }` → метод-цепочка + подметоды (подблоки на отступе 16, `return true` = «строка разобрана»). Проверяет, что каждая строка тела куда-то переехала, и пишет JSON подблоков для сверки | Шаг 7: `TryHebrewHeaders` → 8 подметодов |
| `line_diff.py` | Сверка перенесённого кода со старым построчно без отступов — печатает только отличия | Шаги 6 и 7 |
| `parser_log_dump.cs` | Журнал разбора всех PDF-протоколов фикстур — до/после правки парсера `diff -r` должен быть пуст (ловит и сдвиг порядка проверок, который JSON-эталоны могут не заметить) | Шаг 7 |
| `ef_model_dump.cs` | Слепок EF-модели + дифф против снимка миграций | Шаг 3 |
| `overview_dump.cs` | Ответ обзора соревнования (`GetCompetitionOverviewAsync`, кэш выключен) для списка соревнований/событий/`combined` в JSON-файлы — до/после `diff -r` должен быть пуст. Запускать из снимка (`git archive HEAD server` в scratchpad), «после» — тот же снимок + свои файлы | Шаг 5 |
| `mask_dump.py` | Маскирует метки времени в двух `pg_dump --data-only` для сквозной сверки на копиях базы | Шаг 6 |

Одноразовые скрипты первого уровня (номера строк зашиты) не хранятся — приём: границы блоков →
поля вместо локальных с теми же именами → тела переезжают без правок → компилятор находит
`continue` основного цикла (CS0139) → три независимые сверки (текст, эталоны/тесты, поведение).
