📊 Results


            

                

                    GET
                    /api/results
                

                
Получить результаты соревнований с фильтрацией и пагинацией.

                

                    
ParamTypeInDescription

                    
                        
competitionstringqueryФильтр по названию соревнования (StartsWith)

                        
namestringqueryФильтр по имени/фамилии пловца (StartsWith)

                        
clubstringqueryФильтр по клубу (StartsWith)

                        
styleNamestringqueryФильтр по стилю (exact match)

                        
distancestringqueryФильтр по дистанции (exact match)

                        
genderstringqueryФильтр по полу (exact match)

                        
poolTypestringqueryФильтр по типу бассейна (exact match)

                        
dateFromDateTimequeryДата начала диапазона

                        
dateToDateTimequeryДата конца диапазона

                        
pageintqueryНомер страницы (по умолчанию 1)

                        
pageSizeintqueryРазмер страницы (по умолчанию 100, макс. 500)

                POST
                /api/admin/import
            

            
Импорт результатов из JSON-файла (multipart/form-data). Заполняет справочники и таблицу Results.

            

                Body: multipart/form-data с полем file (.json)

                Response: { totalRows, created, skipped, errors, errorMessages[], message }
            

            
Используйте страницу 📥 Import для загрузки файлов.

        


        
        

            

                DELETE
                /api/admin/import/clear
            

            
Полная очистка импортированных данных. Удаляет Results, Competitions, Clubs, Swimmers, Countries, Relays, Galleries, GalleryItems. Styles и пользователи сохраняются.

            

                Response: { message, deleted: { total, results, competitions, clubs, swimmers, countries, relays, galleries, galleryItems } }
            

            

                
            

            

        


        
        

            

                POST
                /api/admin/swimmers/enrich
                Admin
            

            
Дополнение данных спортсменов (Gender, ClubId, CountryId) из таблицы Results. Заполняет пустые поля на основе самого свежего результата каждого спортсмена. Используется для обратного заполнения ранее импортированных данных.

            

                Response: { message, updated }
            

            

                
            

            

        


        
        

            

                GET
                /api/admin/import-history
                Admin
            

            
История импортов с названиями соревнований. Возвращает массив записей, отсортированных по дате (новые первыми).

            

                Response: [{ id, competitionId, competitionName, competitionDate, importFileName, importDate, approved }]
            

            

                
            

            

        


        
        

            

                PATCH
                /api/admin/import-history/{id}/approve
                Admin
            

            
Обновить статус подтверждения импорта.

            

                
ParamTypeInDescription

                
                    
idintpathID записи истории импорта

                    
approvedboolbodytrue — подтвердить, false — отменить подтверждение
