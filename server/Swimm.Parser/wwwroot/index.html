Swimm Project - PDF Parser

Загрузка PDF-файлов

🏊 IsrOrg (соревнования)
🏅 IsrOrgAgeRecords (рекорды)
🏆 IsrOrgMastersRecords (мастерс)
🌍 WorldRecords (мировые рекорды)
Формат имени файла: <название>_<страна>_<язык>.pdf   Пример: Competition-2025_IL_HE.pdf
Загрузите PDF с рекордами по возрастам. Результат — нормативный JSON (gender → pool → style → distance → age).
Загрузите PDF с рекордами мастерс Израиля. Результат — нормативный JSON (gender → pool → style → distance → age-group). Возрастные группы выше 90-94 игнорируются (эстафеты).
Загрузите XLSX с рекордами (WR + ISR). Результат — нормативный JSON (gender → pool → style → distance → ISR/WR). Все файлы объединяются в один результат.
Или загрузить напрямую с API World Aquatics:
Автоматически скачает 4 файла: WR SCM, WR LCM, ISR SCM, ISR LCM
