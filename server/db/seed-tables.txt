# ── НЕ переносится и почему ────────────────────────────────────────────────
#
# Аккаунты и всё, что на них висит — в проде заводятся заново:
#   Sys_AppUsers, Sys_AppUserRoles, Sys_UserExternalLogins, Sys_UserLocalCredentials,
#   Sys_UserSecurityTokens, Sys_UserLoginHistory, Sys_UserFavorites, Sys_UserMedia,
#   Sys_UserMediaPublications, Sys_UserReactions
#
# Журнал действий администраторов (ActorName / ActorUserId / IpAddress):
#   Sys_AdminAudit
#
# HubGroups и HubGroupMembers — ЕДИНСТВЕННАЯ FK через границу:
#   HubGroups.OwnerUserId NOT NULL → Sys_AppUsers. Без владельца группа не вставится.
#   Локально это одна тестовая группа на 19 участников — в проде создаётся заново
#   за минуту. Вместе с ними не едут и привязанные к пользователям:
#   Sys_HubGroupAdmins, Sys_HubGroupUserMembers, Sys_HubGroupClubRequests, Sys_HubGroupMedia
#
# Приватные тренировки групп (привязаны к HubGroups и к пользователям):
#   Sys_TrainingSessions, Sys_TrainingResults
#
# Заполняются кодом при старте — перенос дал бы конфликт первичных ключей:
#   Sys_AppRoles, Sys_DebugOptions
#
# Журнал проверок целостности — должен отражать прогоны В ПРОДЕ, а не локальные.
# Восстанавливается первым запуском реестра на /Admin/Health:
#   Sys_DataCheckRuns, Sys_DataCheckFindings, Sys_DataCheckStates
#
# Временные хвосты ручных операций — дропнуть перед снятием дампа:
#   tmp_*
